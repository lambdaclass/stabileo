# Release-note metadata and safety-data regression fixes

## Root cause

The 0.5.0 translations were not checked against the published-page metadata
limits, including the ` — Stabileo` title suffix. German and French titles exceeded
120 characters, and the German excerpt exceeded 300. Turkish already fit.
The translation regression flattened and sorted the advisory table, allowing
magnitudes to move between advisories. It also required English numeric spelling,
which retained decimal-looking commas in integer counts in de/fr/tr.

The earlier handoff incorrectly said no COMPLETE flags changed on this branch.
Commit `ba4e77eed` changed `web/src/lib/i18n/locales/complete/{de,fr,tr}.ts`
from `COMPLETE = false` to `COMPLETE = true`. The two new commits leave those
flags true.

## Fix and files changed

- `web/src/lib/blog/translations/{de,fr,tr}/stabileo-0-5-0.ts`: shorten all three
  titles while retaining the additional-advisories and warning-or-refusal meaning
  of English; shorten the German excerpt. Format integer counts with periods
  for de/tr and U+202F narrow no-break spaces for fr.
- `web/src/lib/blog/__tests__/release-0-5-0-translations.test.ts`: compare tables
  by row and cell, preserving advisory IDs, result versions and magnitudes in
  their positions. Normalize local grouping and compare numerical tokens as
  values. Add local integer-count checks and a negative magnitude-swap case for
  each language. The swap takes magnitudes from the actual source cells.
- `web/src/lib/blog/__tests__/translated-search-metadata.test.ts`: check every
  de/fr/tr post against the existing title 25–120 and description 90–300 limits,
  including the title suffix and requiring each translation to exist.
- `changelog.d/release-0-5-0-localized-metadata.md`: changelog entry.
- `.handoff.md`: replace the stale handoff with this report and correct the
  COMPLETE-flag history.

The published-urls-resolve test and its search-metadata helper are unchanged.
No tolerances, baselines or limits were loosened. No engine code or calculated
results changed, so no results-change write-up, registry entry or safety advisory
is applicable. This corrects release-note copy and its regression checks.

## Reproducer and commits

The new checks were first run active: **8 failed, 4 passed** across the two files.

cases in those two files now pass, including the three negative swap checks.
