# German, French and Turkish release notes

## Root cause

The branch marks de/fr/tr complete, but the `stabileo-0-5-0` post had only
English, Spanish and Portuguese bodies. The existing eager blog translation
loader had no corresponding files in `translations/{de,fr,tr}/`, so complete
locale coverage and blog coverage failed and these languages fell back to English.

## Fix and files changed

- `web/src/lib/blog/translations/de/stabileo-0-5-0.ts`
- `web/src/lib/blog/translations/fr/stabileo-0-5-0.ts`
- `web/src/lib/blog/translations/tr/stabileo-0-5-0.ts`

These contain full translations of the English title, excerpt and all 20 blocks,
including image alt text and caption, the advisory table, re-check instructions,
lists and link labels. They follow the existing `stabileo-0-3-0` translation pattern
and are attached automatically by the existing loader. Numbers (including decimal
and thousands separators), versions, issue references, advisory IDs, links and
engineering identifiers retain the English spelling. Engineering terminology uses
Auflager/Schnittgrößen, appuis/efforts internes and mesnet/iç kuvvetler.

- `web/src/lib/blog/__tests__/release-0-5-0-translations.test.ts`: three regression
  cases require a translated title/excerpt and matching block structure, and compare
  each block's numbers, references, selected engineering identifiers, plus signs,
  inequality and percent symbols, and link destinations with English.
- `changelog.d/release-0-5-0-de-fr-tr.md`: changelog fragment.
- `.handoff.md`: this handoff and captured validation output.

No existing assertions, tolerances, baselines or COMPLETE flags were changed.
No files in `engine/` were changed. No engine results changed, so no results-change
registry entry or safety advisory is applicable.

## Reproducer and commits

Commit A: `c3f69dae6` (`test(blog): reproduce missing 0.5.0 translations and safety data`).
The three new tests were run active first and all failed because their respective
release-note bodies were missing; commit A records them with `it.skip.each` and an
explicit known-missing-translation reason. Rust's `#[ignore]` does not apply to
Vitest, and there is no numerical-result issue number for this content defect.

Commit B: `fix(blog): translate 0.5.0 release notes into German French and Turkish`.
Adds the translations, removes the skips and known-missing reason, and checks
plus/inequality/percent symbols as well. All three regression cases pass.
