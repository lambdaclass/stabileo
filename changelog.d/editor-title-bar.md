### Changed
#### One title bar for the editor, and the panel on the left (2026-11-26)

On a desktop, Basic and PRO share one title bar. It holds the project button (|||), home, a File menu, save, undo, redo and a history timeline, followed by the project tabs. On the right are the panel-side switch, Discord, Send a comment (it reaches the team's inbox, and asks for an account first), help, the language, the assistant, contact and settings. The mode switch (Basic 2D, Basic 3D, Professional) sits at the left of the ribbon. The right-hand panel opens on the left by default; the switch in the title bar moves it back and remembers the choice. The view controls float at the foot of the model: pointer, zoom to fit, home view and the view menu. Phones are unchanged.

Examples and tutorials leave the Project panel. An empty tab shows "Start a model": blank, three examples drawn from their own geometry, and links to every example and to the tutorials; "Don't show at start" turns it off. File gains Open example… (one gallery for Basic and PRO, every card with its preview) and View tutorials (every walkthrough, any published video, and a link to the Stabileo YouTube channel).

A tab is one model, and Basic 2D, Basic 3D and Professional are three ways of working on it: the mode switch lists the three, each tab shows its mode, and switching keeps the model. Going up asks nothing. Coming down from Professional asks only when the model holds what Basic computes differently (slabs and walls, diaphragms and rigid links, connectors, a scoped self-weight rule), and then opens a simplified copy in a new tab, leaving the Professional tab as it was. Cutting or projecting a 3D model to 2D opens the plane model in a new tab too, and "erase the model" gives way to "continue in a new tab".

PRO's project data (client, job, signatures, revisions), its regulations and the office templates leave the Project panel for File › Project properties…, a dialog with one page each; the links that opened them (the report, the load generator, the building, the command search) open its page. The Project panel keeps saving, opening, sharing, import, export and the autosave status. In Basic, the 2D/3D button leaves the ribbon on a desktop, where the mode switch beside it does the same.

The docked panel has one width in Basic 2D, Basic 3D and Professional (440 px by default; dragging it in one mode resizes it in all and is remembered), and Basic opens with it on Model data › Nodes, as Professional already did; once closed, it starts closed. The landing's footer and the contact menus list contact@stabileo.com, and Instagram is marked as written in English.
