#### Live RC column pushover example (2026-11-03)

/examples/rc-pushover pushes a reinforced concrete cantilever column sideways with fibre sections (Hognestad concrete, bilinear steel). It shows the pushover curve, the initial stiffness beside 3EcIcr/L³ of the cracked section, and the largest load carried beside the peak of the same section's moment–curvature curve, which the page integrates independently. CIRSOC 201 Mn/L is shown for comparison. A run that passes the peak is shown as stopped at its last converged load factor, never as complete. In six languages.
