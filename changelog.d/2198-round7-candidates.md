### BREAKING (results)

#### Retain supported secondary cages and size only the effective seismic ends

Column candidates now retain stronger secondary-leg counts for both editions, including when no supported spacing-table seed is available. Beam and rectangular-column spacing seeds use each candidate's stirrup diameter. Seismic end sizing ignores a shared support cage when both ends explicitly override it. These corrections can recover previously refused cages and change selected reinforcement. Existing verification requirements and search bounds remain unchanged. See the [round-7 results record](../docs/results-changes/2198-round7-candidates.md) (#2198).
