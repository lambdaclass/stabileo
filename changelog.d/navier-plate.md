### Added
#### Navier plate mesh convergence

First version (stage `first-version`, 0 reviews) at `/research/benchmarks/navier-plate`: one uniformly loaded, simply supported rectangular plate, DKT and MITC4 mesh refinement through the production WASM wrapper, the shared Stabileo viewer, and centre displacement compared with the Navier series and a published worked example. Includes precomputed replay, live recomputation, English/Spanish/Portuguese text and an explicit not-yet list. MITC9 is not exposed by the current web wrapper. This is research, not a design tool.
