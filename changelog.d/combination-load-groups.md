### BREAKING (results)

#### Respect load groups when generating combinations

Saved combination rules apply grouped factors only to cases with the matching load symbol and group. An unresolved group blocks generation and Apply. Each set of alternatives contributes one case, even when separate terms name the alternatives. Auto Loads can resolve a named group from retained cases and creates an ordinary case when the planned target is a composite. See [the results change](../docs/results-changes/2026-11-combination-load-groups.md). (#2535)
