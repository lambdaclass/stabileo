### BREAKING (results)

#### Use each direction’s width for the active-torsion minimum

Provided concrete beam cages now check the combined shear and torsion minimum with each shear direction’s own width. Low secondary shear in a deeper-than-wide section can change a torsion pass to a failure; recompute affected cages and review secondary reinforcement (#2198). See the [results write-up](../docs/results-changes/2198-round20-torsion-minimum.md).
