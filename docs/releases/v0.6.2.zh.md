# Stabileo 0.6.2：已更正的杆件内力恢复、设计验算和生成荷载

[English](v0.6.2.md) · [Español](v0.6.2.es.md) · [Português](v0.6.2.pt.md) · [Deutsch](v0.6.2.de.md) · [Français](v0.6.2.fr.md) · [Magyar](v0.6.2.hu.md) · [Türkçe](v0.6.2.tr.md) · **中文**

发布于 2026-11-18。本说明涵盖自 **v0.6.1** 以来的变更。完整记录见 [CHANGELOG.md](../../CHANGELOG.md)。

## 您的结果可能会变化：请重新运行受影响的项目

请重新运行受影响的混凝土和钢结构验算以及杆件荷载分析。对于受影响的生成雪荷载、屋面和楼面面荷载，**请先重新生成荷载**，再重新运行荷载工况、组合、包络和相关的设计验算。仅对已存储的荷载重新求解并不能修复它们。请将挠度、内力需求、配筋、利用率、控制组合和证书与已经采用的结果对比。复核已交付的计算以及据此做出的截面设计。拒绝、不可用的量或未验算的配筋都不是通过的答案，也不是零需求。

请重新生成受影响的风荷载，以及从属宽度模式下的重力和地震作用。伴随雪荷载基准受影响时，请重新生成雪荷载组合。重新运行分析之前，请对照预期约束复核方向不明确或类型未知的 3D 支座。

## 其他变更

提供了匈牙利语版本说明和公开页面文案。Mohr 应力计算和分享链接保留较小的非零应力；支座反力的教学说明已更正。登录过程中结果发生变化时，报告和下载会被拒绝。可选的研究、工具和弯矩图游戏新增内容仍默认关闭；现有公开页面仍可访问。

自动生成的荷载以及钢筋混凝土设计和构造结果现在附有审计通知，并链接到尚未关闭的审计发现。非线性分析在求解过程中保持响应，并支持进度显示和取消。大型 3D 组合和重复的设计验算复用更多计算结果。首页轮流展示实时结构图形。可选的研究合集新增一个基于 Heyman《The Stone Skeleton》的砌体拱实验。

## 已知局限

**已知的错误结果仍未修复。** 对荷载生成和混凝土设计的内部审计正在进行，仍有尚未关闭的发现。本版本没有修复下列问题。使用前请阅读其影响范围，并独立核实受影响的结果。

- 生成的重力、风、雪和地震荷载：[#2202](https://github.com/lambdaclass/stabileo/issues/2202)、[#2208](https://github.com/lambdaclass/stabileo/issues/2208)、[#2209](https://github.com/lambdaclass/stabileo/issues/2209)、[#2218](https://github.com/lambdaclass/stabileo/issues/2218)。
- 混凝土配筋和杆件验算：[#2212](https://github.com/lambdaclass/stabileo/issues/2212)、[#2213](https://github.com/lambdaclass/stabileo/issues/2213)、[#2214](https://github.com/lambdaclass/stabileo/issues/2214)、[#2215](https://github.com/lambdaclass/stabileo/issues/2215)、[#2216](https://github.com/lambdaclass/stabileo/issues/2216)、[#2217](https://github.com/lambdaclass/stabileo/issues/2217)、[#2225](https://github.com/lambdaclass/stabileo/issues/2225)。
- 杆件荷载的内力恢复和受约束支座的反力：[#2226](https://github.com/lambdaclass/stabileo/issues/2226)、[#2227](https://github.com/lambdaclass/stabileo/issues/2227)。
- 地面运动的对称性：[#2125](https://github.com/lambdaclass/stabileo/issues/2125)。

- **[SA-2026-056](../advisories/SA-2026-056-constrained-shell-dynamic-invariance.md) 仍未修复：** 对于重新编号、旋转或单位换算后结果明显变化的、带约束的框架与壳混合模型，请独立核实其动力需求。尚无确定的保守修正系数。
- 2D 塑性倒塌分析在 [#758](https://github.com/lambdaclass/stabileo/issues/758) 解决之前仍会被拒绝，见 [SA-2026-044](../advisories/SA-2026-044-plastic-2d-invariance.md)。经认证的 3D 下限并不认证原始的塑性铰发展过程。
- 时程分析不提供支座的总动力需求。请使用计入惯性、阻尼和支座荷载的独立分析。不支持的索分析，以及索/时程分析流程中非零的支座强制位移，都会被明确拒绝。未增加空间弧长法和位移控制求解器。
