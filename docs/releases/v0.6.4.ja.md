## 結果が変わる場合があります: 影響を受けるプロジェクトを再実行してください

影響を受ける Basic の反力モーメントと自由体の表示を再確認し、部材の集中荷重を一覧にした Basic と PRO のレポートを再生成してください。その符号と軸を、釣合いと意図した荷重方向に照らして比較してください。

解析する前に、反転した部材の分布荷重について、元の向き、載荷区間、端部の強度を確認してください。影響を受ける旧来の平面の集中荷重を修正し、各偶力が意図したモーメントになっているか確認してください。板の外形と開口をメッシュと比較し、古いメッシュや適合しない壁とスラブの接合部を修正してください。7 階建ての例題ギャラリーまたは建築 DXF の例題を使った場合は、修正版を読み込み直してください。影響を受ける解析、荷重組合せ、移動荷重のスイープを再実行し、支配的な部材の断面力、変位、設計検定を確認してください。コンクリートの引張面と描かれた配筋を確認し、ピークまたは 4 分点のモーメントを使った鋼の検定を再実行してください。結果を信頼する前に、拒否を解決してください。

## その他の変更

- Basic は、3D の支点反力モーメントをソルバーの全体座標の符号で表示します。自由体の表示は選択した座標軸を使い、2D の節点側の矢印と一致します。Basic と PRO は、集中力と偶力の成分を、ソルバーの平面と座標軸で報告します。影響を受ける確認を再実行し、レポートを再生成してください。[#2396](https://github.com/lambdaclass/stabileo/pull/2396)

- PRO は、無効または古い板メッシュが残っている場合や、壁とスラブの接合部が適合しない場合、解析を拒否します。メッシャーは、適用の前に、完全で有効な外形と穴を必要とします。更新した 7 階建てのギャラリーと建築 DXF の例題には、適合する接合部のメッシュがあります。メッシュ化された新しい CAD の素案は、スラブと壁の着目点をそろえます。モデルのみのワークブックのエクスポートには、メッシュ化されていない板を含めることができます。[#2409](https://github.com/lambdaclass/stabileo/pull/2409)

- 部材図と移動荷重の包絡線は、着目点の間のピーク、集中作用の両側、部材端のすぐ内側の力を回復します。正確な極値が得られない場合、組合せ図はラベル付きの安全側の限界を示すことができます。あいまいな着目点、解決されない支配的なピーク、不完全な設計用の着目点グリッドは、影響を受ける結果をブロックします。反転したコンクリートのスパン区間は、実際の引張面を保持します。鋼の検定は、釣合いのピークと 4 分点のモーメントを使い、必要な図の情報が不完全な場合は、曲げモーメント勾配の考慮を保留します。着目点の多いレポートは、準備済みの図を再利用します。[#2403](https://github.com/lambdaclass/stabileo/pull/2403)

- CIRSOC 201-2025 は、ねじりに対する最小横補強筋を両方向で検定し、鉄筋かごがある場合は、純ねじりに評価されたコンクリートの限界を使います。描かれた鉄筋かごに、周囲の鉄筋、二次方向の有効せい、接合部をまたぐ鉄筋の定着の根拠がない場合、ねじりとせん断の検定は拒否することがあります。せん断の検定は、サンプリングした着目点の間も含め、切断位置に存在する別個の引張鉄筋を使います。7 階建ての例題では、以前は合格していた検定に対する拒否が表示される場合があります。[#2433](https://github.com/lambdaclass/stabileo/pull/2433)

- 部材の反転コマンドは、どちらも、分布荷重の向き、載荷区間、端部の強度を保持します。解析は、旧来の平面の偶力の欄にある、あいまいさのないゼロでない値を使い、矛盾する値は拒否します。空間モデルでは、使える部材への射影がなくても、純粋な始端偶力を、指定した節点に適用できます。射影を必要とするその他の旧来の作用は、解析をブロックする場合があります。[#2456](https://github.com/lambdaclass/stabileo/pull/2456)

- 復元した平面の集中偶力や節点モーメントに対する有限値の編集は、ゼロに設定した場合も含め、保存されたモーメントを置き換えます。矛盾した、または無効なモーメントは、保存して開き直したあとでも解析をブロックします。意図したモーメントを確認し、入力し直して、解析と設計を再実行してください。[#2467](https://github.com/lambdaclass/stabileo/pull/2467)

- 再メッシュは、板で指定された中間点を通る曲線の境界に従います。あいまいな掃引は、再メッシュと解析をブロックします。境界を確認し、古いメッシュを作り直して、解析と設計を再実行してください。再メッシュは、シェルのオフセットと曲率の編集を、一意で完全に一致するセルにのみ移します。編集したシェルが一致しない場合、再メッシュは停止し、既存のメッシュを保持します。シェルの特性を意図したモデルと照らして確認し、以前に失われた編集を復元して、解析と設計を再実行してください。[#2466](https://github.com/lambdaclass/stabileo/pull/2466)

- 3D の配筋ワークスペースが速く開くようになり、詳細なモデルでの保存、復元、タブの切り替えで、不変の配筋ジオメトリを再利用します。元に戻すとやり直しは、コンクリートの形状に合った配筋詳細を復元します。[#2438](https://github.com/lambdaclass/stabileo/pull/2438), [#2444](https://github.com/lambdaclass/stabileo/pull/2444), [#2458](https://github.com/lambdaclass/stabileo/pull/2458)

- AI キーの設定で、プロバイダーのボタン、キーの入力欄、キーの操作は、縦横とも最小 44 CSS ピクセルになりました。[#2440](https://github.com/lambdaclass/stabileo/pull/2440)

- 公開されている Mattiasson のエラスティカ、MacNeal–Harder、シェルの障害物コースのリサーチページには、最初のベンチマーク実行の完了した結果、または報告された拒否が表示されます。[#2445](https://github.com/lambdaclass/stabileo/pull/2445)

- 製品ロードマップでは、独立した荷重と板面積の検定、厳密な断面力関数、完全な設計の根拠、変換をまたいで検定する 1 つの標準モデルを優先します。[#2469](https://github.com/lambdaclass/stabileo/pull/2469)

## 既知の制限

**誤った結果を出す既知の不具合は未解決のままです。** 影響範囲を読み、使用前に関連する結果を独立して検証してください。

- 静的地震の生成では、非常に薄い質量帯や、ほぼ一致するねじりの支持部材で、作用が失われる場合があります。旧来のモード荷重の通知が、古い荷重が残ったまま消える場合もあります。[SA-2026-086](../advisories/SA-2026-086-seismic-static-story-forces.md) と [SA-2026-087](../advisories/SA-2026-087-seismic-modal-load-generation.md) を参照してください。
- 積雪荷重の伝達、コンクリートの配筋、部材荷重の回復、拘束された反力については、未解決の指摘が残っています。[製品ロードマップ](../roadmap/PRODUCT_ROADMAP.md)を参照してください。開示済みの片側の積雪ねじりの仮定は、独立して考慮してください。[#2224](https://github.com/lambdaclass/stabileo/issues/2224)
- **[SA-2026-056](../advisories/SA-2026-056-constrained-shell-dynamic-invariance.md) は未修正のままです。** 番号の付け替え、回転、単位変換のあとで大きく変わる、拘束された骨組とシェルの混在モデルの動的作用力を、独立して検証してください。安全側の補正係数は確立されていません。
- 2D の塑性崩壊は拒否されたままです。保証された 3D の下限は、その下限にのみ適用されます。時刻歴解析では、慣性、減衰、支点荷重を含む動的な支点作用力の合計について、引き続き独立した検証が必要です。[SA-2026-044](../advisories/SA-2026-044-plastic-2d-invariance.md)
- 独立したケーブル張力の検定では、ケーブルの自重を含めてください。[SA-2026-015](../advisories/SA-2026-015-cable-tension-chord-law.md)
