# Stabileo 0.6.0：已更正的结果、明确的拒绝与支座位移

[English](v0.6.0.md) · [Español](v0.6.0.es.md) · [Português](v0.6.0.pt.md) · [Deutsch](v0.6.0.de.md) · [Français](v0.6.0.fr.md) · [Türkçe](v0.6.0.tr.md) · [Magyar](v0.6.0.hu.md) · **中文**

发布于 2026-11-13。本说明涵盖自 **v0.5.0** 以来的变更。完整记录见 [CHANGELOG.md](../../CHANGELOG.md)。

## 您的结果可能会变化：请重新运行受影响的项目

请重新运行受影响的荷载工况、组合以及完整的非线性或分阶段历程。将位移、杆件内力、反力和设计需求与您已经采用的结果对比。复核已交付的计算以及据此做出的截面设计。请按每份公告查看其受影响的输入和用户应采取的行动。拒绝或不可用的量不会提供替代答案：它既不是零需求，也不是通过的验算。

## 安全

- 针对 RUSTSEC-2026-0538，将 quinn-udp 从 0.5.14 更新到 0.5.16，修复了在数据报被截断后接收循环可能空转的问题。
- 针对 RUSTSEC-2026-0486，将 rustix 从 1.1.4 更新到 1.1.6，修复了扩展属性函数中长度为零的缓冲区所引起的不健全问题。
- Revert Check（受信任）使用基准分支的工作流和检查器；拉取请求的提交仅作为数据获取，绝不会被检出或运行。标签是实时读取的；无法读取的 `reverts-ok` 标签绝不会计入。

## 其他变更

- 生成的平面结构获得明确的约束，厂房默认采用物理支撑。请重新生成并复核支座和支撑；已保存的模型不变。
- Fehér、Sipos 和 Várkonyi 的弯曲板条形状控制实验，提供了交互式求解器、作动器路径，以及英语、西班牙语和葡萄牙语的论文对比。切割板条的摘要也已翻译成西班牙语和葡萄牙语。
- 0.5.0 的博客发布文章现已有完整的德语、法语和土耳其语译文。塑性证书的警告和资源拒绝已翻译成所有提供的语言。

## 已知限制

- **SA-2026-056 仍未修复：** 对于在重新编号、旋转或单位转换后结果显著变化的带约束框架与壳混合模型，请独立验证其动力需求。尚未确立保守的修正系数。
- 2D 塑性倒塌在 [#758](https://github.com/lambdaclass/stabileo/issues/758) 完成之前仍被拒绝，如 [SA-2026-044](../advisories/SA-2026-044-plastic-2d-invariance.md) 所述。经认证的 3D 下限并不认证原始的铰历程。
