## 結果が変わる場合があります: 影響を受けるプロジェクトを再実行してください

影響を受ける静的地震、パネルモードの重力、屋根段差の積雪の各ケースは、**まず荷重を再生成し**、そのうえで解析、荷重組合せ、包絡線、およびそれに依存する設計検定を再実行してください。古い生成荷重のまま解析すると、その荷重の配置が繰り返されます。生成がブロックされた場合は、報告された問題を解決して荷重を再生成するか、保存済みの荷重を独立して検証した荷重に置き換えてから、結果を信頼してください。Stabileo が以前に生成したモード地震ケースは、静的な方法が適用できる場合に限り、静的ケースに置き換えてください。使用できない場合は、モデルを信頼する前にお知らせに従ってください。

影響を受ける詳細な断面応力度の照会、2D の移動荷重のスイープと軸力の影響線、および 2D の自重ルールを明示的に使った解析や荷重ケース係数の繰り返しを使った解析を再実行してください。自重をオフにした状態で取り込んだ重力設定が残っている保存済みプロジェクトでは、明示的な 2D の自重ルールがなくても、単独の解析を再実行してください。影響を受ける例題やフィクスチャは、元のソースから読み込み直してください。反力、部材の断面力、たわみ、配筋、支配的な荷重組合せ、検証の状態を、すでに使用した値と比較してください。影響を受けるレポート、ワークブック、エクスポートを再生成して確認してください。これには、2D 自由体インスペクターの全体座標の端部モーメントの符号に依存したものも含まれます。拒否は解決するか、独立した検定を行ってから、影響を受けた結果を使用してください。

影響を受ける静的地震ケースを持つ、ブレース付き骨組、分割された傾斜部材、勾配屋根では、再生成後に階の力、ベースシア、垂木の作用を比較してください。

影響を受けるワークブックは元のデータから取り込み直し、座標、荷重、重力、拘束を確認してから、モデルを再実行してください。ばねや拘束を含む影響を受けるワークブックは再エクスポートしてください。影響を受けるコンクリートの検証を再実行してください。CIRSOC 201 の検証は、現在の配筋図に対して再実行し、支配的な荷重組合せ、判定、レポートを確認してください。

## その他の変更

静的地震の生成は、支点の基準面を確定できない場合や、地震質量に関与する構造に接続された支点の高さが異なる場合にブロックされます。それらの支点が基準面を決めます。生成は、分離した形状、支点より下にある関与質量、無効なシェルの形状、対応していない伝達や偶然ねじりでもブロックされます。モード荷重の生成は、ケースを作成する前にブロックされます。モード、周期、刺激係数は引き続き利用できます。パネルモードの重力は、同一平面のシェルの重なりや、オフセットしたシェルデッキへの剛連結によって被覆があいまいになる場合にブロックされます。モデルを確認し、報告された状態を解決してから荷重を再生成してください。

ローカルのローラーの向きを変えたり、部材のない 3D の Z ローラーを、フレームが定義されないまま回転させたりする編集は、拘束を保持できない場合に拒否されるようになりました。古いスナップショットの意図した拘束を確認してください。ケーブルおよび地盤と構造の相互作用の Web ワークフローでの有限でない支点ばね剛性と、ゼロでない係数が完全に打ち消し合う荷重組合せも、拒否されます。座標軸を宣言したワークブックは、対応していない荷重や支点の成分、あいまいな欄、無効な強制回転を含む場合、現在のモデルを置き換える前に却下されます。コンクリートの検証は、対応していない検定を拒否し、その理由を示し、それらの検定には保証を発行しません。詳細な断面応力度は、合成応力度を表示できない場合も、個々の成分を表示します。

全体座標軸エディターは**デフォルトでオフ**です。有効にすると、選択した座標軸がエディター、モデルコード、ワークブック、図面、レポートに適用され、ソルバーは標準の座標を使います。

利用規約とプライバシーポリシーのページ、それらへのフッターのリンク、結果の免責事項が公開されました。ログインは引き続き無効です。[#2358](https://github.com/lambdaclass/stabileo/pull/2358)

アプリ全体と公開ページで簡体字中国語が利用できます。工学的な解説と再確認の通知も更新しました。結果の警告が表示されている間も、層間変形角のコントロールを操作できます。3D の応力表示は、支点の上にポインターを置いても応答性を保ちます。鉄筋の検証が保留されている間も、スラブと柱の点接合の通知が表示されます。大規模な線形解析と繰り返しのコンクリートスパン検定は、処理量が減りました。ランディングの図は、ポインターを置いても動き続けます。ログインしていない状態のプロジェクト操作では、アカウントが必要な操作が示されます。

- 静的地震の生成は、ブレースの交差部と屋根の接合部で床の根拠を確認します。棟梁だけでは床を確定できません。直線の部材分割は、平行移動のあとも一貫して識別され、座標の精度が不十分な場合や階があいまいな場合は、生成がブロックされます。両端に床の根拠がある場合、持ち上がった垂木には、関与するスパンに沿って分布慣性が与えられます。確定した床は、連続した傾斜区間も床の接合部で分割します。これにより、階の力、ベースシア、垂木の曲げとたわみが変わる場合があります。[#2404](https://github.com/lambdaclass/stabileo/pull/2404)
- パネルの重力荷重の生成は、重なった梁ベイとシェルデッキの両方に荷重が載り、デッキの継ぎ目が、継ぎ目から外れたマスター節点を介して完全に拘束されている場合の、荷重経路の重複をブロックします。自動荷重も、座標の丸め誤差によって重力の支持部材の勾配の分類が不確定になる場合、プレビューの前にブロックします。この分類は、以前は平面の回転や部材の分割のあとで変わる場合がありました。平屋根と勾配屋根で、積雪の生成は、現場の段差の吹きだまりを部材に伝達する必要がある場合や、その適用可否を確定できない場合にブロックされます。以前の伝達では、力と偏心モーメントが失われる場合がありました。[#2406](https://github.com/lambdaclass/stabileo/pull/2406)
- ワークブックの取り込みは、同じ名前になるシート名、重複した見出し、必須の見出しの欠落、無効な単位、スプレッドシートのエラー、矛盾する拘束フラグ、入力のある未対応の荷重欄を却下します。平面の荷重では、モデル平面内にある、宣言された 2 本のワークブック座標軸のどちらかまわりの、ゼロでないモーメント成分を却下します。拒否された取り込みでは、現在のモデルがそのまま残ります。完全な明示的拘束は、解析前のエクスポートを含め、宣言されたワークブックの座標軸で保持されます。平面の回転ばねは `kr [kN·m/rad]` としてエクスポートされ、旧来の見出しも引き続き読み込めます。[#2395](https://github.com/lambdaclass/stabileo/pull/2395)
- CIRSOC 201 の検証は、あばら筋の間隔に同時に作用する軸力を使い、モーメントがちょうどゼロになる位置で定着を検定し、局所的なあばら筋の区間を検定します。耐震フープの限界は、端部の鉄筋のすべての層を考慮します。ねじり耐力と検定比は、評価された低いほうの限界を反映します。描かれた端部を超える鉄筋や、未検証の周囲鉄筋の定着がある場合、検定はブロックされることがあります。コンクリートのみの二次せん断検定では、上側のあばら筋の 2 つの折曲げ部の両方に納まる主筋が必要です。最終せいの再検定は、差し替えの梁の図面が提供されている場合はそれを使います。柱リストは、混在する鉄筋径を保持し、指定した鉄筋かごを再現できない場合は、物理的な配筋詳細を表示しません。[#2398](https://github.com/lambdaclass/stabileo/pull/2398)
- 板メッシュのクリアが速くなりました。スラブメッシュの再構築時も同様です。2D の共回転解析は共通の非線形ドライバーを使い、既存の Newton 法と修正 Newton 法の結果を保持します。[#2394](https://github.com/lambdaclass/stabileo/pull/2394)

## 既知の制限

**誤った結果を出す既知の不具合は未解決のままです。** 影響範囲を読み、使用前に関連する結果を独立して検証してください。

- 静的地震の生成では、非常に薄い質量帯や、ほぼ一致するねじりの支持部材で、作用が失われる場合があります。旧来のモード荷重の通知が、古い荷重が残ったまま消える場合もあります。[SA-2026-086](../advisories/SA-2026-086-seismic-static-story-forces.md) と [SA-2026-087](../advisories/SA-2026-087-seismic-modal-load-generation.md) を参照してください。
- 積雪荷重の伝達、コンクリートの配筋、部材荷重の回復、拘束された反力については、未解決の指摘が残っています。[製品ロードマップ](../roadmap/PRODUCT_ROADMAP.md)を参照してください。開示済みの片側の積雪ねじりの仮定は、独立して考慮してください。[#2224](https://github.com/lambdaclass/stabileo/issues/2224)
- **[SA-2026-056](../advisories/SA-2026-056-constrained-shell-dynamic-invariance.md) は未修正のままです。** 番号の付け替え、回転、単位変換のあとで大きく変わる、拘束された骨組とシェルの混在モデルの動的作用力を、独立して検証してください。安全側の補正係数は確立されていません。
- 2D の塑性崩壊は拒否されたままです。保証された 3D の下限は、その下限にのみ適用されます。時刻歴解析では、慣性、減衰、支点荷重を含む動的な支点作用力の合計について、引き続き独立した検証が必要です。[SA-2026-044](../advisories/SA-2026-044-plastic-2d-invariance.md)
- 独立したケーブル張力の検定では、ケーブルの自重を含めてください。[SA-2026-015](../advisories/SA-2026-015-cable-tension-chord-law.md)
