# Stabileo 0.6.1：已更正的杆件验算与雪荷载

[English](v0.6.1.md) · [Español](v0.6.1.es.md) · [Português](v0.6.1.pt.md) · [Deutsch](v0.6.1.de.md) · [Français](v0.6.1.fr.md) · [Türkçe](v0.6.1.tr.md) · [Magyar](v0.6.1.hu.md) · **简体中文**

发布于 2026-11-15。本说明涵盖自 **v0.6.0** 以来的变更。完整记录见 [CHANGELOG.md](../../CHANGELOG.md)。

## 您的结果可能会变化：请重新运行受影响的项目

请重新运行受影响的混凝土和钢结构设计验算。对于生成的雪荷载，**请先重新生成荷载**，再重新运行受影响的荷载工况、组合、包络和相关的设计验算。仅对先前保存的荷载重新求解并不能修复它们。请将需求、承载力、配筋、利用率、控制组合和证书与已经采用的结果对比。复核已交付的计算以及据此做出的截面设计。拒绝、不可用的量或未验算的配筋都不会提供通过的答案，也不是零需求。

## 安全公告

下列五份严重程度为高的公告已在 **0.6.1** 中修复。请按每份公告查看其受影响的输入和用户应采取的行动，即使先前的结果已通过或已获认证。

| 公告 | 严重程度 | 变更内容与应采取的行动 |
|---|---|---|
| [SA-2026-064](../advisories/SA-2026-064-steel-cb-combination.md) | 高 | 钢结构的 Cb 可能取自另一个组合，或取自未定位的短无支撑跨（#1316、#2088）。请重新运行 CIRSOC 301 钢结构验算，并复核受弯承载力、相互作用利用率和控制组合。 |
| [SA-2026-065](../advisories/SA-2026-065-snow-roof-step.md) | 高 | 在坡屋面的受雪面上，屋面高差处的雪堆积可能被遗漏（#2082）。请重新生成 CIRSOC 104 雪荷载，并重新运行受影响的分析和设计验算。 |
| [SA-2026-066](../advisories/SA-2026-066-cirsoc201-transverse-cm.md) | 高 | 当支座之间有横向荷载时，混凝土的 Cm 仍可能获得端弯矩折减（#2089）。请重新验算细长的混凝土柱和墙、放大后的弯矩以及配筋。 |
| [SA-2026-067](../advisories/SA-2026-067-snow-roof-rotation.md) | 高 | 平面旋转可能改变生成的雪荷载（#2093）。请按实际屋面几何重新生成荷载，再重新运行分析和验算；把旧模型转回去并不是修复。 |
| [SA-2026-068](../advisories/SA-2026-068-provided-torsion-stirrups.md) | 高 | 在设计箍筋不足的情况下，扭转验算仍可能通过（#2141）。请重新运行混凝土设计验算，并复核实际的横向承载力、箍筋间距和扭转破坏。未验算的纵向配置不是一个通过验算的钢筋笼。 |

## 其他变更

混凝土和钢结构验算保留来自同一组合和同一站点的内力。组合或站点数据不完整时，现在会拒绝，而不是借用端点结果。所需配筋状态与已提供配筋状态保持分离，缺少纵向抗扭配置时会明确报告。重复的相同设计工作会被复用，同时每项需求仍会被验算。与旧项目的对比现在保留已发布的材料和截面默认值；已保存的项目和迁移不变。

## 已知限制

- **已知的错误结果仍未解决：** [#2096](https://github.com/lambdaclass/stabileo/issues/2096)、[#2142](https://github.com/lambdaclass/stabileo/issues/2142)、[#2143](https://github.com/lambdaclass/stabileo/issues/2143) 和 [#2144](https://github.com/lambdaclass/stabileo/issues/2144)。本版本并未修复它们。请查阅其受影响的范围，并在使用前独立验证受影响的结果。
- **[SA-2026-056](../advisories/SA-2026-056-constrained-shell-dynamic-invariance.md) 仍未修复：** 对于在重新编号、旋转或单位转换后结果显著变化的带约束框架与壳混合模型，请独立验证其动力需求。尚未确立保守的修正系数。
- 2D 塑性倒塌在 [#758](https://github.com/lambdaclass/stabileo/issues/758) 完成之前仍被拒绝，如 [SA-2026-044](../advisories/SA-2026-044-plastic-2d-invariance.md) 所述。经认证的 3D 下限并不认证原始的铰历程。
- 时程分析不提供总的动力支座需求。请使用包含惯性、阻尼和支座荷载的独立分析。不受支持的索分析，以及索/时程工作流中非零的强制支座位移，会被明确拒绝。
- 空间弧长法和位移控制求解器尚未添加。现有的警告和限制仍然适用。
