# Stabileo 0.6.4：修正杆件结果、板分析和混凝土验算

[English](v0.6.4.md) · [Español](v0.6.4.es.md) · [Português](v0.6.4.pt.md) · [Deutsch](v0.6.4.de.md) · [Français](v0.6.4.fr.md) · [Magyar](v0.6.4.hu.md) · [Türkçe](v0.6.4.tr.md) · **中文**

发布于 2026-11-21。本说明涵盖自 **v0.6.3** 以来的变更。完整记录见 [CHANGELOG.md](../../CHANGELOG.md)。

## 您的结果可能会变化：请重新运行受影响的项目

重新查看 Basic 中受影响的支座反力矩和自由体读数，并重新生成列出杆件集中荷载的 Basic 和 PRO 报告。根据平衡条件和预定荷载方向核对符号和坐标轴。

求解前，核对反向杆件上分布荷载的原始方向、加载区间和端部强度。修正受影响的旧版平面集中荷载，并核对各力偶的预定力矩。对照板轮廓和孔洞检查网格，修正过期网格或不相容的墙板接缝。用过示例库的七层建筑或建筑 DXF 示例时，请重新加载修正后的示例。重新运行受影响的分析、组合和移动荷载扫描，然后检查控制内力、位移和设计验算。核对混凝土受拉面和详图中的钢筋，重新执行曾使用峰值或四分点弯矩的钢结构验算。处理拒绝原因后再采用结果。

## 其他变更

- Basic 按求解器的全局符号显示三维支座反力矩。自由体检查使用所选坐标轴，二维模型中节点一侧的读数与箭头一致。Basic 和 PRO 报告按求解器的平面和坐标轴列出集中力与力偶分量。请重新检查受影响的读数并重新生成报告。 [#2396](https://github.com/lambdaclass/stabileo/pull/2396)

- 如果模型仍有无效或过期的板网格，或墙板接缝不相容，PRO 会拒绝分析。板轮廓和孔洞完整且有效后才可应用网格划分。示例库的七层建筑和建筑 DXF 示例已在接缝处使用相容网格。新划分网格的 CAD 草稿会对齐楼板和墙的网格点。仅导出模型的工作簿可以包含尚未划分网格的板。 [#2409](https://github.com/lambdaclass/stabileo/pull/2409)

- 杆件内力图和移动荷载包络计入测站之间的极值、集中作用两侧的值以及紧靠杆端内侧的内力。组合内力图无法求得精确极值时可以显示明确标注的保守界限。测站有歧义、控制极值无法确定或设计测站不完整时，系统会阻止输出受影响的结果。混凝土跨段内的反向杆段保留实际受拉面。钢结构验算使用满足平衡的峰值和四分点弯矩。内力图数据不全时不采用弯矩梯度的有利影响。包含许多测站的报告会复用已准备好的内力图。 [#2403](https://github.com/lambdaclass/stabileo/pull/2403)

- CIRSOC 201-2025 在两个方向验算受扭所需的最小横向配筋，有钢筋笼时，纯扭验算采用计算得到的混凝土限值。当钢筋详图无法证实周边纵筋、次方向受剪有效高度或跨接缝锚固时，受扭和受剪验算可能被阻止。受剪验算计入截面上实际存在的不同受拉钢筋，包括采样测站之间的截面。七层示例中原先通过的验算现在可能被拒绝。 [#2433](https://github.com/lambdaclass/stabileo/pull/2433)

- 两种杆件反向命令均保留分布荷载的方向、加载区间和端部强度。分析采用旧版平面力偶字段中无歧义的非零值，并拒绝相互冲突的值。空间模型中，即使杆件没有可用投影，也可在原定起始节点施加纯起点力偶。仍需投影的其他旧版荷载可能阻止求解。 [#2456](https://github.com/lambdaclass/stabileo/pull/2456)

- 对恢复的平面集中力偶或节点力矩输入有限值时，该值会替换已保存的力矩，包括输入零。相互冲突或无效的力矩在保存并重新打开项目后仍会阻止分析。请核对预期力矩，重新输入，再运行分析和设计验算。 [#2467](https://github.com/lambdaclass/stabileo/pull/2467)

- 重新划分网格时，板的曲线边界沿经过指定中间点的圆弧布置。圆弧有歧义时会阻止重新划分网格和分析。请核对边界，重建过期网格，再运行分析和设计验算。 重新划分网格时，壳单元的偏置和曲率修改只会转移到唯一且完全匹配的单元。若找不到匹配单元，重新划分网格会停止并保留现有网格。请核对壳单元属性，恢复此前丢失的修改，再运行分析和设计验算。 [#2466](https://github.com/lambdaclass/stabileo/pull/2466)

- 三维钢筋工作区打开更快。在有配筋详图的模型中，保存、恢复和切换标签页会复用不可变的钢筋几何。撤销和重做会恢复与混凝土几何相符的配筋详图。 [#2438](https://github.com/lambdaclass/stabileo/pull/2438), [#2444](https://github.com/lambdaclass/stabileo/pull/2444), [#2458](https://github.com/lambdaclass/stabileo/pull/2458)

- AI 密钥设置中的服务商按钮、密钥字段和密钥操作在两个方向上均至少为 44 CSS 像素。 [#2440](https://github.com/lambdaclass/stabileo/pull/2440)

- 已发布的 Mattiasson 弹性线、MacNeal–Harder 和壳单元综合测试研究页面会显示首次基准运行的最终结果或报告的拒绝信息。 [#2445](https://github.com/lambdaclass/stabileo/pull/2445)

- 产品路线图优先安排独立核查荷载和板面积、采用精确内力函数、完善设计验算依据，以及统一模型表示并检查各种变换。 [#2469](https://github.com/lambdaclass/stabileo/pull/2469)

## 已知局限

**仍有已知错误结果。** 使用前请查阅影响范围，并独立复核相关结果。

- 静力地震荷载生成仍可能在很薄的质量带和几乎重合的扭转传力构件中丢失作用。旧版振型荷载的提示也可能在荷载仍保留时消失。见 [SA-2026-086](../advisories/SA-2026-086-seismic-static-story-forces.md) 和 [SA-2026-087](../advisories/SA-2026-087-seismic-modal-load-generation.md)。
- 雪荷载传递、混凝土配筋、杆件内力恢复和受约束支座反力仍有待解决的问题。请独立考虑已披露的单侧雪荷载扭转假设。见[产品路线图](../roadmap/PRODUCT_ROADMAP.md)和 [#2224](https://github.com/lambdaclass/stabileo/issues/2224)。
- **[SA-2026-056](../advisories/SA-2026-056-constrained-shell-dynamic-invariance.md) 仍未修复。** 对于重新编号、旋转或换算单位后结果明显变化的受约束框架与壳体混合模型，请独立验算动力需求。目前尚无确定的保守修正系数。
- 二维塑性倒塌分析仍会被拒绝。三维认证适用于下限。时程分析中的支座总动力需求须独立验算，并计入惯性、阻尼和支座荷载。见 [SA-2026-044](../advisories/SA-2026-044-plastic-2d-invariance.md)。
- 独立复核索拉力时，请计入索的自重。见 [SA-2026-015](../advisories/SA-2026-015-cable-tension-chord-law.md)。
