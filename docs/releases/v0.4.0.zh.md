# Stabileo 0.4.0：设计模块在完成前默认关闭，以及四项安全修复

[English](v0.4.0.md) · [Español](v0.4.0.es.md) · [Português](v0.4.0.pt.md) · [Deutsch](v0.4.0.de.md) · [Français](v0.4.0.fr.md) · [Türkçe](v0.4.0.tr.md) · [Magyar](v0.4.0.hu.md) · **简体中文**

发布于 2026-10-28。完整的技术记录见 [`CHANGELOG.md`](../../CHANGELOG.md)；安全公告见 [`docs/advisories/`](../advisories/README.md)。

> **关于时间的说明。** stabileo.com 会部署合并到 `main` 的每一项变更，因此下列修复在 2026 年 10 月 21 日至 26 日之间随各自的合并陆续上线。应用会显示一次结果可能已变化的通知；在某项相关变更之前保存的项目，打开时会显示重新验算提示。

> **规范设计现在在 PRO 中默认关闭。** 截面设计、规范验算（CIRSOC 201、301 等）、配筋、构造和图纸仍在开发中。PRO 启动时只提供建模、荷载与组合、分析及其结果、计算导出和 IFC；这些都不需要设计。要使用设计，请开启 **设置 → PRO → “开启规范设计（开发中）”**，该选项会列出其尚未覆盖的内容。该选择按浏览器记忆。已包含设计内容（钢筋、构造、决策）的项目，在关闭设计时会保留全部内容，并提示是否开启。设计关闭期间，其任何功能都不会运行：不做截面设计，不做规范验算，重新运行时也不做验证。

在 0.3.0 之后，我们把验证的重点从求解器转向其周边：应用生成的荷载、设计验算，以及从求解到设计的路径。由此又发现了四个可能给出错误或偏不安全结果的缺陷，其中一个为严重。它们均已修复，并且每一个都有一份已发布的安全公告，说明了问题所在、受影响的对象以及需要重新验算的内容。

---

## 1. 您的结果可能会变化：请重新运行项目

请重新运行使用下列功能的项目，并与您已经采用的结果对比。每一行都链接到其公告，其中有算例以及对已交付结果的处理建议。

| 公告 | 问题所在 | 严重程度 | 受影响的对象与需要重新验算的内容 |
|---|---|---|---|
| [SA-2026-021](../advisories/SA-2026-021-free-roof-wind-minimum.md) | 自由屋面（CIRSOC 102）：沿屋脊方向完全没有风荷载，横跨屋脊方向则小于 §2.1.5 规定的最小值 0,75 kN/m² × Af（在 20 m/s 时仅为其 17 %） | 高 | 使用自由屋面结构（棚架、雨篷、停车场屋顶）的自动风荷载。请重新验算纵向支撑、其连接以及柱的弱轴弯曲 |
| [SA-2026-022](../advisories/SA-2026-022-earth-pressure-dead-load-resisting.md) | 存在土压力 H 时，恒荷载起抵抗作用的 CIRSOC 101 组合（0,9 D + 1,6 H、1,2 D + 1,6 H）从未生成（某算例中偏低 27 % 至 45 %） | 高 | 含 H 荷载的模型（墙上的土压力，或一个 H 荷载工况）。请重新验算挡土墙和地下室墙的倾覆、滑移和反向弯矩 |
| [SA-2026-023](../advisories/SA-2026-023-column-moment-sign.md) | CIRSOC 201 柱验算只读取弯矩的一个符号：一侧面钢筋较多的布置按其较强一侧通过验算（φMn 最多偏高 38 %） | 严重 | 设计器给出 6、10、14、18 或 22 根钢筋，或相对两面钢筋不等的单向受弯钢筋混凝土柱。请重新验算所有曾通过验算的此类柱；重新运行设计可能会增加钢筋 |
| [SA-2026-024](../advisories/SA-2026-024-design-on-unfactored-results.md) | 当组合已定义但未求解时（实时计算、组合求解失败，或激活列表为空），基础、节点、楼板、墙和钢结构优化器按未放大的荷载设计：某算例偏低 15 %，D + L 偏低 29 % 至 38 % | 高 | 带组合的 PRO 3D 模型，其设计是在开启实时计算时、组合求解失败后或没有激活组合时读取的。请重新求解并重新设计；在带组合的模型中，列出“当前结果集（未求解组合）”的基础即是按此方式设计的 |

**其他会改变结果的变更**（不是带公告的缺陷；每一项都在重新验算提示中，并在 [`docs/results-changes/2026-10-design-chain.md`](../results-changes/2026-10-design-chain.md) 中说明）：

| 变更 | 受影响的对象与需要重新验算的内容 |
|---|---|
| 模态、反应谱和时程分析，以及地震和风荷载方案中的模态步骤，会拒绝杆件插入偏移和壳偏移：它们此前是在节点线上求解的，没有计入静力分析所采用的偏心（#460） | 带偏移且依赖模态或反应谱结果的模型。在动力分析链支持偏移之前，请使用静力地震力，或移除偏移 |
| CIRSOC 301 钢结构验算结论（#461）：引擎无法评估的极限状态会使构件处于「未评估」的保留状态，而不是判为不通过；未声明的制造方式（轧制或焊接）和荷载作用高度会按两种情况验算；H.1 按同时作用的力评定，因此部分比值下降；按各轴和各翼缘取无支撑长度；验算弱轴剪力（G.6）；0.95 至 1.00 显示为警告 | 开启设计后验算的钢构件。冷弯型钢截面不再按热轧型钢套用 CIRSOC 301 验算：CIRSOC 303 尚未实现，因此其显示为未设计，此前的通过结果不能作为有效验算 |
| 铝、木和组合构件由各自的验算器验算，不再按 CIRSOC 301 钢结构处理（#463） | 开启设计后验算的这些材料的构件 |
| 混凝土梁（#462、#475）：未声明其侧向作用的梁，按侧向体系的一部分设计；验算最小抗剪配筋和扭转；楼板下的直立梁按其梁高方向设计，而不是按双向受弯被拒绝 | 开启设计后验算的混凝土梁 |
| 墙下条形基础沿整条基础验算，而不是在墙的每一英尺下单独验算（#475） | 开启设计后设计的墙基础 |

**另有变更：** 风荷载的场地海拔现在接受低于海平面的数值，此时 Ke 大于 1（#581）。

## 2. 以警告或拒绝取代悄然出错

- **不再在未求解的组合集上做设计。** 当存在需要设计的组合而它们均未求解时（或仅激活了 SRSS 或 ABS 组合，或激活列表为空），所有设计都会拒绝并说明原因。当组合被拒绝或求解失败时，“重新运行分析和设计”会失败，项目仍标记为需要重新运行。
- **设计无法评估的内容显示为「未评估」或「保留」，** 并附原因，绝不会计为通过。
- **动力分析拒绝杆件偏移和壳偏移，** 而不是忽略它们继续求解（见上文）。
- **对不存在的杆件或节点施加的荷载会被拒绝，** 并指明荷载及其编号，求解和重新编号时均如此。此前，这样的杆件荷载会被悄悄跳过，而重新编号可能把已删除支座的沉降转移到另一个支座上。
- **当索自身重量产生的张力超过其张力的四分之一且没有预张力时，会给出警告：** 被当作索输入的重型构件通常是桁架杆。
- **重新验算提示涵盖上述全部内容，** 现在还会指出此前漏掉的 0.3.0 修复，针对在其合并与发布之间的某个构建上求解的项目。

## 3. 其他修复

- **组合路径在发布结果前检查 NaN 位移，** 与单次求解相同；并且每次手动求解都会取消待处理的实时计算，后者可能对一个未改动的模型报告“模型已更改”。
- **只有一种手动求解。** Enter、功能区、导出以及钢结构优化器的重新验证，都经由与“计算”相同的求解及其检查；在自重或求解设置变更之前开始的求解，也不再把其答案以新的设置发布。
- **钢筋编号计入每一条箍筋肢。** PRO 验证报告曾把 4 肢箍筋按一个 2 肢封闭箍筋统计，因此其下料单和钢材重量漏掉了内部的肢；现在它们按拉筋列出，并且该表已翻译（此前打印的是内部键名）。仅影响数量。
- **默认钢材声明其极限强度。** 每个新模型默认使用的“Acero A36”没有 Fu，因此新模型的每项 CIRSOC 301 验算都显示“未评估”，直到用户输入。现在它的 Fu = 400 MPa。
- **删除或重新编号不再把荷载留在别人会占用的编号上：** 删除楼面荷载定义会一并删除其荷载，删除杆件会一并删除其预应力筋，删除节点会一并删除其强制位移，并且反应谱的编号不会再次分配（针对已删除反应谱的反应谱工况，曾在新反应谱的表上求解）。
- **编辑反应谱会使在旧反应谱上求解的结果失效，** 撤销和重做也同样如此。此前，在 0.4 g 反应谱上求解的 D + Ex，在反应谱改为 0.8 g 之后仍留在屏幕上。
- **PRO 的包络 DXF 绘制的是包络。** 它曾绘制由每端最大力构成的某一个荷载状态（在一根包络峰值为 49.16 的梁上为 320.59 kN·m）；包络集和 SRSS 集不再写入变形图。

## 4. 新增

- **设计链，位于上述开关之后：** 混凝土设计与构造、其他材料与规范、文档和设计工作区。它仍在开发中。它与一栋重建的六层建筑原设计的比较属于内部回归检查，而不是独立验证。
- **带用户账户的服务器后端** 已进入代码库。它在生产环境中关闭：应用与以前一样，无需账户。
- **PRO 建模，迈向整栋建筑：** 板作为实体对象，按需划分网格，诊断位于“分析”行；曲杆作为整体构件，荷载沿弧线分布，以及带弧形边的板；跨多个标高的 DXF 模板、CAD 式捕捉，以及 CAD 向导中的分层平面图；按楼层划分的使用区，其活荷载取自 CIRSOC 101 表，以及面层。被网格切开的杆件，其荷载保留在各段上，IFC 导入会让曲线边的每一段直线都保留在各自的点上。
- **索预张力。** 规格 › 杆件 › 索 接受预张力（kN），引擎据此设定索的无应力长度。这解决了 0.3.0 中关于重型索的限制（#527）；没有预张力时，绘制的弦长即为无应力长度，与以前相同。

## 5. 更快、更小

- **落地页和博客的加载量为 0.46 MB，而不是 6.4 MB：** 它们不再下载整个应用和引擎。应用在其第一个屏幕上加载它们，与以前相同。
- **引擎缩小了 25 %**（由 12.0 MB 降到 9.0 MB），现在使用 `wasm-opt` 优化。CI 在每次运行时都会在 184 个确定性算例上检查，优化后的引擎与未优化的引擎给出逐位相同的结果。
- **面向贡献者：** 引擎的测试由 104 个二进制文件改为构建 7 个（重新构建快三倍），`make test-changed` 和 pre-push 钩子运行最可能受某项变更影响的测试，端到端测试套件以十个均衡的分片运行，并对不稳定的测试设有隔离机制。

## 6. 已知限制

- 与 [0.3.0](v0.3.0.md#4-known-limitations) 相同，但重型索除外，现在可以设置预张力。
- 规范设计仍在开发中；其尚未覆盖的内容列在其开关之下：冷弯型钢（CIRSOC 303）不做设计，单轴对称钢截面的 E.4 不评估，EC3 侧向扭转屈曲（6.3.3）仅部分评估。
- 动力分析会拒绝带杆件偏移或壳偏移的模型（IFC 计算模型带有偏移）。
