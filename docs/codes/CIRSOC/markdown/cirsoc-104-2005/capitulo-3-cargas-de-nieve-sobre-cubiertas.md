PLANAS, pf

La carga de nieve, pf    , sobre una cubierta con pendiente igual o menor que  5°, se debe
determinar utilizando la siguiente expresión:

                                                pf = 0,7 CeCt Ι pg            [ kN/m2]                                                                    (1)

El valor de p                 f debe ser mayor o igual que los siguientes valores mínimos para las cubiertas
con baja pendiente que se especifican en el artículo 3.4.

 pf = Ι pg, (factor de Importancia multiplicado por  pg)  para                                                                                                                                pg ≤ 1 kN/m   2
