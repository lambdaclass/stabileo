# Feature × analysis support matrix

Generated by `engine/tests/feature_matrix.rs`; do not edit by hand. Regenerate with

```sh
cd engine && UPDATE_FEATURE_MATRIX=1 cargo test --release --test feature_matrix
```

Every analysis must either honour a model feature or refuse it by name. Each cell runs the
analysis on a small model where the feature matters, on the same model without the feature,
and on an independent reference (the same structure expressed without the feature, an
analytical value, or the linear solver in the linear limit).

| Symbol | Meaning |
|---|---|
| ✓ | supported: matches the independent reference |
| R | refused with an error naming the feature |
| ~ | the feature changes the answer, but no independent reference exists for this analysis |
| · | not applicable: the feature does not change this analysis' answer |
| E | error that does not name the feature |
| IGN | silently ignored: the answer equals the model without the feature |
| BAD | wrong: matches neither |
| K | known IGN/BAD/E being fixed on another branch (see the notes) |
