## Root causes and independent evidence

### SSI residual plateau — #2011

This is a single, unreleased cantilever with a full-length varying transverse load, one fixed support and no soil springs. Exact compatibility rank is full. The independent cantilever calculation uses only its stored geometry, section, material and load. The accompanying script constructs binary64 displacement fields whose high-precision, dimensionally weighted physical residuals are approximately `6.1e-12` and `7.2e-12` in the two frames, below the unchanged requested `1e-10`. The refusal is therefore not explained by a physical mechanism or an inherently unrepresentable response at that requested residual.

In SSI's no-soil case, every iteration solves the same secant matrix and force vector afresh. A failed residual check does not produce a correction to that solution. Once rounding leaves the rotated solve above the new residual criterion, fifty repetitions cannot improve it. The original converges; the rotated copy exhausts the iterations, including in public WASM. The adjacent parent/child replay pins this regression to #1940. The solution is explicitly unconverged, not a silent wrong result. Keep #2011 open. A fix should share elastic solution/refinement with the ordinary linear reduction, and address the corresponding 2D/3D and native/WASM reductions without changing the residual criterion.

### Constraint rounding bound — #2013–#2018

All six adapters share the same four-node frame/truss model and linear MPC. Independent exact rational rank, on the exact binary64 coordinates and MPC coefficients, is **11 of 12**, before and after the saved rotation. The only zero-energy motion is the unused spin at node 4; every translation is stiffened. The remaining constrained stiffness is positive at both independent arithmetic precisions. Thus this is not a translated mechanism like the five mechanism families below.

The original zero-free-load case solves. Rigidly rotating/reflection-transforming its MPC causes the shared constraint-reduction rounding bound to refuse it. The failure is already present on the previous nightly engine. Keep #2013 as the primary issue; #2014–#2018 are exact-model/alternate-entry duplicates. #1930 discusses related released-direction projection, but this 2D input uses the default released-rotation representation; an identical implementation cause has **not** been proved, so it is not proposed as a duplicate of #1930. The design follow-up is an admissible-subspace strain representation and a rounding bound that preserves exact unloaded gauge directions, shared by every constrained entry point. No threshold is loosened here.

### Released-rotation load projection — #2023, #2035, #2036, #2039, #2058, #2064, #2066, #2067

All eight witnesses have the same three nodes and two frame members. High-precision physical rank is **17 of 18**. ## Handoff and limitations

Proposed closures are in `.close-1113.md`; larger engine/harness follow-up text is in `.issues-1113.md`; candidate evidence for the coordinator is in `.silent-1113.md`. No issue was actually closed, relabelled or commented on. The signed commits are local only.

A rank calculation proves the physical nullspace; it does not itself quantify every double-precision admission limit. A compatible released-spin load proves a false loaded-axis check; it does not validate the original model's warned large-displacement response. The nonlinear angle check proves the exact units finding is a winding artefact; it does not establish uniqueness of the model's nonlinear equilibrium. Runtime results depend strongly on instrumentation, compiler and machine. The archive records unsuccessful builds and mode differences rather than treating them as successful reproductions.

No root-cause engine refactor is implemented in a triage-only change. Proposed shared elastic refinement, physical constrained strain/gauge representation, load projections with propagated uncertainty, and recovery-aware fuzz assertions are deliberately left to the respective owners. Their scope includes solver design and cross-entry contracts; an isolated threshold or message-substring adjustment would hide this class of defect. Repetition is prevented in the **reproducer registration** by exact issue keys, preserved seeds, nonempty-pass assertions and parent-failure evidence; repetition of the **engine defects** is not claimed impossible while the fifteen tests remain ignored.

Review #2070 also strengthens the #2019 independent oracle: displacement IDs must be exactly `{1, 2, 3}` and reaction IDs exactly `{1, 3}`, with each ID occurring once, before values are inspected. Empty, missing, duplicate and unexpected IDs are exercised against the same verifier as the real Certified response; the complete response remains accepted. This changes verification only, with no engine-result or tolerance changes.
