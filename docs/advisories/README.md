# Safety advisories

Advisories for released versions that produced wrong or unconservative results. The process,
severity scale, notification channels, timelines and template are in
[../SAFETY_ADVISORIES.md](../SAFETY_ADVISORIES.md).

**SA-2026-001…020 are published** (2026-10-21, with release 0.3.0): SA-2026-001…004 are
retroactive, for defects fixed in 0.2.0; SA-2026-005…020 were fixed in 0.3.0. Each has a GitHub
issue labelled `safety-advisory`, a section in the release notes and an entry in the in-app
re-check registry where the app could produce the result. **SA-2026-021…024 are published**
(2026-10-28, with release 0.4.0): they were fixed in 0.4.0, and each has its issue, release-notes
section and re-check registry entry in the same way. **SA-2026-025…047 are published**
(2026-11-07, with release 0.5.0): all but SA-2026-044 were fixed in 0.5.0 (SA-2026-040 is a
containment), and each has a section in the release notes and, where a saved project's results
change, an entry in the in-app re-check registry. SA-2026-025, 026, 034, 035 and 039 have none, as
each advisory says: re-cut models cut from 3D (SA-2026-035) and re-import models imported from Excel
or IFC (SA-2026-039). SA-2026-044 is not fixed: 2D plastic collapse stays refused until
[#758](https://github.com/lambdaclass/stabileo/issues/758) is fixed. **SA-2026-048 is published**
(2026-11-08): it was fixed after 0.5.0, live on stabileo.com since 2026-11-08, and its re-check
registry entry is `cb-segment-ends`. **SA-2026-049…053 are published**
(2026-11-09): they were fixed after 0.5.0 and are live on stabileo.com since 2026-11-09.
Their fixes are #1780 (SA-2026-049, merged 2026-11-09 07:41:41 UTC), #1784
(SA-2026-050, merged 2026-11-09 01:53:37 UTC) and #1783 (SA-2026-051…053,
merged 2026-11-09 09:27:10 UTC). Their re-check registry entries are
`support-spring-conflicts-refused`, `non-finite-analysis-results`, `moving-loads-3d`,
`moving-axial-patch-boundaries` and `moving-load-endpoint-forces`, respectively.
