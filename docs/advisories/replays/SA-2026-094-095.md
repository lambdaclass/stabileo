# WASM replays for SA-2026-094 and SA-2026-095

The replay uses the production 2D solver adapter, the WASM solver and,
for SA-2026-094, the global member and node inspectors and the free-body
moment arrows. Run the [same test](sa-2026-094-095.test.ts) at
`04c610dcc86a36cb20ed0114760cbf0d09a221dd` (main before #2364) and
`9452c5b7489eac5a13913a55667baad5ea03a49e` (the #2364 merge). With the
target revision checked out, keep a copy of the test source at the path
below and run these commands.

```sh
make web.deps
make wasm
make shell
cp docs/advisories/replays/sa-2026-094-095.test.ts web/src/lib/canvas/__tests__/advisories-094-095.replay.test.ts
make test.web.unit FILE=src/lib/canvas/__tests__/advisories-094-095.replay.test.ts VITEST_WORKERS=1
rm web/src/lib/canvas/__tests__/advisories-094-095.replay.test.ts
```

The test prints the measurements before checking them against equilibrium.
Use the same test path on each revision. The transverse-load and scoped-weight
cases fail on the first revision and pass on the second. The pure-axial and
legacy-gravity controls pass on both.

- [SA-2026-094 output](SA-2026-094.json) records the signed global moments
  and the moment sum about the support. The recovered forces and reactions
  are identical between revisions.
- [SA-2026-095 output](SA-2026-095.json) records the standalone, case and
  combination reactions. Both revisions returned results with no warning
  or refusal. The ordinary informational solver diagnostics are retained.
