# Consistent RC beam-line and member checks

CIRSOC beam verification uses the diameter of the stirrup being checked to establish primary shear depth. Previously the beam-line draft used the evaluated diameter while checks of the same member cage used the section default. The two paths now use the same depth basis for shear strength, minimum steel and stirrup spacing. Drawn zones still control where the drawing supplies coverage, including checks on both sides of transitions.

Support embedment rows report required length divided by available length. A layout that clears the column cage has zero joint interference. A layout that fails the joint check has no finite utilization because there is zero allowable interference.

Re-run verification on affected CIRSOC beams. The shear utilization, governing check or verification verdict may change.
