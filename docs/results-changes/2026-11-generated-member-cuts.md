# Generated member cuts and invalid plastic states (2026-11-16)

Rerun analyses that split members carrying distributed loads. Earlier unmerged #2222 code compared a nominal cut distance with a length independently measured from the generated child coordinates. Exact equality refused ordinary translated or rotated models. The CI trapezoidal axial-load witness also refused a child measured as `1.2499999999999998` for a nominal span of `1.25`. A horizontal member from `1000.1` to `1004.1`, divided into thirds, is a regression witness.

All web splitters now measure source cut distances from the generated child geometry through shared partition validation. The generated chain must remain on the original member line, in order, and its measured lengths must partition the source length within floating-point arithmetic error. The checks account for coordinate subtraction, interpolation and accumulation; they do not introduce an engineering acceptance tolerance. Non-finite, reversed, collapsed, bent or length-inconsistent geometry refuses. The existing relative load-interval limit and its boundary assertions remain unchanged.

The final boundary retains the original source endpoint. If subtraction and length measurement give slightly different widths, the shared remapper maps the source coordinate and load density together. For a child of length `l`, source boundaries `s0`, `s1`, and `r = (s1 - s0) / l`, it uses `x = s0 + r*u` and `q_child(u) = r*q_source(x)`. Change of variables therefore conserves the load resultant and its first moment in source coordinates, including opposing endpoint intensities. Generated geometry agrees with those coordinates within the checked arithmetic error. This is not permission to stretch a genuinely inconsistent member. Source intervals and every positive overlap still pass the existing interval validation, including the refusal of sub-limit fragments. No load is silently omitted or replaced by a force couple.

The shared path covers manual splitting, analysis subdivision, variable members, planar second-order refinement, Maxwell section evaluation and plastic hinge splitting. Both model dimensions and all distributed-load components use it. Recovery positions for refined and variable members now follow the measured cuts too. Native solvers do not perform these web model transformations; integration tests solve the generated inputs through WASM in both dimensions, with linear and nonlinear analysis.

Plastic collapse also previously cleared nodal moments whenever a released-state rank check was invalid. A successful moment-free probe could then turn unrelated invalid data, including a non-finite generated moment, into a collapse claim. The engine now returns a structured unsupported-nodal-moment kind only when its existing moment-support check refuses and complete validation succeeds after clearing finite nodal moments. The exception requires that kind and finite nodal moments. It never branches on diagnostic wording. Every other invalid or unavailable result remains an error. Initial invalid models always refuse. Real finite-moment released mechanisms retain their existing answers.

These two regressions were introduced on the unmerged branch. No new safety advisory is added. Earlier main exposure of rounded load remapping is documented in the preceding results record and worktree evidence; advisory decisions remain with the coordinator. The separately deferred opposing-intensity axial cancellation and extreme-intensity slope overflow are unchanged.

The registry entry declares solve availability and plastic status quantities. Numerical corrections to partial distributed loads remain covered by `narrow-partial-loads`; `generated-member-cuts` does not explain arbitrary displacement, reaction or member-force changes in full-length loaded models. In particular, the legacy cable-stayed bridge's recorded correction remains tied to its recorded response fingerprints.

Manual edits request the shared load-partition geometry only when the member has a load to transfer. Cutting an unloaded member at an existing node within the editor's established weld tolerance needs no load-coordinate mapping. Nodal loads and loads on other members remain untouched. A member carrying a distributed, point, thermal or prestress load still takes the strict shared geometry path before the edit commits. Off-line loaded cuts still refuse atomically. Automatic subdivision and variable-member recovery retain their geometry checks.

Embedded flat-2D manual cuts use node-to-node geometry for the parent, every child and every load-coordinate length, matching the existing 3D embedding that does not expand offsets. Previously the parent alone omitted offsets while the children retained them in partition validation, so a loaded member with saved nonzero offsets could refuse an otherwise valid split. One geometry transformation now supplies the complete partition; saved member offsets remain on the edited members. True 3D cuts retain flexible-segment geometry. Full and partial distributed loads solve after all six manual cut routes, with prescribed force and first moment checked through planar and embedded 3D linear and nonlinear WASM paths. This restores edit/solve availability on the unmerged branch; it does not change the solver's answer for the same input.

Unavailable plastic rank checks preserve the analyzer's existing localized diagnosis, including its reason and retry instruction, at initial and released-state checks. The same diagnosis is already translated in all seven shipped locales. The error remains a refusal, and invalid-input handling is unchanged. WASM fiber acceptance tests independently compare applied and reaction totals with the original fixture nodal force, so two zero totals cannot certify a dropped load.

Analysis subdivision and variable-member expansion now use that same model-aware geometry API, together with manual cuts. Parent bounds, every child length and variable-member recovery positions share the existing embedding decision. A planar member from `(0, 0)` to `(6, 0)` with axial offsets `+0.25` and `-0.25` uses length `6` throughout the embedded analysis. The unmerged branch instead treated its distributed load as lying on length `5.5`: `[0, 6]` refused, while some supported partial loads returned incorrect reactions. For a linearly varying load from `-2` to `-4` over `[1, 5]`, the prescribed vertical resultant is `-12`; analysis subdivision on the parent branch returned a support reaction of approximately `12.609375` rather than `12`. The shared geometry restores the prescribed load and first moment. Recovery reports the node-to-node length and stations for embedded models. True 3D members still use their flexible geometry, including offsets. The strict interval and generated-geometry checks are unchanged. Partial-load numerical corrections are also covered by the `narrow-partial-loads` registry entry.

The automatic embedded full-load refusal is introduced by this unmerged branch. Extracting the corresponding web transformations from `origin/main` at `d972912815c7ccae3d41af9a242e54c5911eb575` also reproduces incorrect variable-member load totals: the same planar member carrying `-2` to `-4` over `[0, 5.5]` yields a vertical reaction of approximately `18` instead of the prescribed `16.5`. Main's analysis-subdivision path also mismeasures loads on true 3D offset members. These are returned numerical results, distinct from the branch's false refusal. The worktree handoff records the source replay and the existing offset-editor warning for the coordinator's exposure assessment; no advisory is assigned here.
