Issues #2013–#2018 describe one false-refusal family. The exact archived four-node frame/truss model has a linear MPC and one unused rotation at node 4. The retained triage in `docs/verification/triage/2026-11-13.md` proves binary-rational compatibility rank 11/12 before and after the saved rotation. No translation is free. The loads act at the fixed node, giving an independent zero-displacement, zero-member-force solution, with the support reaction opposite the applied load.

The previous check formed the valid nonnegative input envelope `H = |C|ᵀ |K| |C|`, projected it into the local whitening basis as `P = |W|ᵀ H |W|`, then reduced it to one maximum row sum. Multiplying that maximum by the condition number of the whole retained stiffness combined soft directions and cancellation from different parts of the space. A change of frame could move this sufficient scalar estimate across the refusal limit without changing the physical constrained space. This was an explicit error on origin/main, not a silent wrong engineering result; no advisory is added.

The shared stability analysis now retains the directional envelope. Write `S = Wᵀ Cᵀ K C W` for the retained stiffness and `D = diag(P 1)`. For every symmetric input perturbation bounded entrywise by `η P`,

`|xᵀ δS x| ≤ η |x|ᵀ P |x| ≤ η xᵀ D x`.

The second inequality follows termwise from `2 |x_i x_j| ≤ x_i² + x_j²`. Therefore positive definiteness of `S − D / RESOLVABLE` proves positive physical stiffness under the bounded perturbation at the existing refusal limit. The envelope includes contributions that cancel during reduction and is widened for its accumulation rounding using each row’s contributing entries. Unrelated DOFs cannot enlarge that row’s allowance. Its projection occurs once; the same retained envelope supplies the check for every caller. No scalar maximum from another retained direction multiplies it. Translation mechanisms, nonfinite inputs, physical conditioning, coupling, load-on-spin and recovered-response checks remain in force.
