# Constraint reduction retains directional rounding uncertainty

Issues #2013–#2018 describe one false-refusal family. The exact archived four-node frame/truss model has a linear MPC and one unused rotation at node 4. The retained triage in `docs/verification/triage/2026-11-13.md` proves binary-rational compatibility rank 11/12 before and after the saved rotation. No translation is free. The loads act at the fixed node, giving an independent zero-displacement, zero-member-force solution, with the support reaction opposite the applied load.

The previous check formed the valid nonnegative input envelope `H = |C|ᵀ |K| |C|`, projected it into the local whitening basis as `P = |W|ᵀ H |W|`, then reduced it to one maximum row sum. Multiplying that maximum by the condition number of the whole retained stiffness combined soft directions and cancellation from different parts of the space. A change of frame could move this sufficient scalar estimate across the refusal limit without changing the physical constrained space. This was an explicit error on origin/main, not a silent wrong engineering result; no advisory is added.

The shared stability analysis now retains the directional envelope. Write `S = Wᵀ Cᵀ K C W` for the retained stiffness and `D = diag(P 1)`. For every symmetric input perturbation bounded entrywise by `η P`,

`|xᵀ δS x| ≤ η |x|ᵀ P |x| ≤ η xᵀ D x`.

The second inequality follows termwise from `2 |x_i x_j| ≤ x_i² + x_j²`. Therefore positive definiteness of `S − D / RESOLVABLE` proves positive physical stiffness under the bounded perturbation at the existing refusal limit. The envelope includes contributions that cancel during reduction and is widened for its accumulation rounding using each row’s contributing entries. Unrelated DOFs cannot enlarge that row’s allowance. Its projection occurs once; the same retained envelope supplies the check for every caller. No scalar maximum from another retained direction multiplies it. Dropped soft directions retain their previous conservative condition-product guard; an exact zero-scale gauge still requires a zero input envelope. Translation mechanisms, nonfinite inputs, physical conditioning, coupling, load-on-spin and recovered-response checks remain in force.

The change affects admission and thus the availability of every result field in constrained linear, load-session, staged, creep, certified and initial P-Delta analyses. Re-run affected refusals. Previously admitted analyses retain the same assembly, reduction, factorization, loads and recovery; this change supplies no replacement engineering values.

The regression set contains one hand-checked exact-model test per issue and the existing six seeded rotation/mirror tests. The class tests exercise native and public WASM entry points, 2D and all three coordinate-plane 3D embeddings, zero and free-node axial loading, reflected and rotated copies, and a pinned unused spin. The loaded oracle uses axial elongation `u₂ = F (x₂ − x₁) / (EA)`, rigid translation of the unloaded continuation, zero extension of the truss and the MPC to determine node 4. It does not use an engine solve as its baseline. Copies without the translational MPC must refuse. The synthetic matrix test separates cancellation and conditioning into distinct blocks and tests both sides of the unchanged cancellation and physical-conditioning boundaries. Small disconnected cantilevers exercise the sparse threshold and PCG-selected entry calls without altering the answer or the cancellation boundary.

A full element-strain assembly representation is not introduced: the input envelope already bounds the actual rounded global reduction. Keeping that envelope directional fixes its misattribution without changing element stiffness assembly or the solvers' numerical answers. P-Delta class cases pin the unused spin; its separate unpinned tangent refusal is outside this reduction check.

## Review audit: redundant fixed-node constraints (#2075)

The existing `truss_balance_1969` control expected a rounding refusal when an equal-displacement constraint tied node 1 to node 3 in the x direction. Both nodes are already fixed, so this tie leaves the physical space unchanged. The directional check admits the model; retaining that admission requires an independent answer, rather than preserving an old sufficient-bound refusal as a baseline.

`docs/verification/constraint-rounding-2075.py` reads the archived `nodal-1969` fixture as exact binary rationals. It builds rational axial and frame compatibility rows and computes their rank after the restraints. The rank is 16 of 18 free DOFs, with exactly the unused rotations at nodes 5 and 7 left free. The redundant tie has identical rank and identical displacements to the model without the tie. The node-2 x restraint used as an admitted control has rank 15 of 17 free DOFs, with the same two free spins.

The same standalone audit independently assembles the stiffness from axial strain and the two end-slope differences, using the fixture's section/material properties and the documented modulus conversion. It solves the active system by decimal Gaussian elimination with pivoting at 80 and 110 digits. All displacement components agree within `1e-60`; the largest active equilibrium residual at 110 digits is below `1.3e-93`. The redundant-tie matrix's diagonally scaled infinity-norm condition estimate is `4.352708541520e+08`, well below the unchanged `1e12` refusal limit. Its largest displacement component is `1.839887357304e+02` in the fixture's displacement units. This is a linear solution audit; it makes no assertion about the physical validity of a finite-displacement interpretation.

The checked-in audit output supplies the displacement oracle for native dense/sparse constrained calls and the public WASM constrained exports in 2D and the XZ embedding. The embedding reverses the in-plane rotation component because its plane normal is negative y. The former refusal expectation now requires an answer matching that oracle. No stiffness, solver, refusal limit, response tolerance or engineering baseline is changed in this review revision. This admission is part of the directional-bound change described above; the origin/main stability implementation gives an explicit rounding refusal in the independent-answer replay, rather than a silent incorrect answer.

The public WASM class runner now captures the model dimension separately from each constraint. Successful admitted and refused P-Delta executions are required in both dimensions, so losing all 2D P-Delta cases fails the runner. The review also changes the targeted `IGNORED=1` invocation to include both ignored and unignored tests, preserving the six seeded constrained-release regressions. The rounding-boundary and mechanism controls remain unchanged.
