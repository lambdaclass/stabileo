# Atomic member splits and load-conserving geometry (2026-11-16)

A manual member split now computes its nodes, sections, member properties, load fragments and identifiers in temporary containers. All load validation finishes before the model or undo history changes. Refusal leaves the complete saved model and identifier counters unchanged, including variable sections.

Distributed loads must retain the geometry on which their coordinates and intensities were defined. Previously a nominal child span could be stretched to its rounded geometric length while retaining its intensities. On the reported nominal span of `4/3` generated as `1.375`, a constant load's resultant increases by 3.125%. An implicit full-span endpoint in main's older splitter has the same problem. First moments can change too.

This round-9 behavior is superseded by [generated member cuts](2026-11-generated-member-cuts.md), which restores ordinary translated and rotated models using measured geometry and conservative integral mapping. The round-9 shared web remapper required exact equality between the source span and generated child length. It checks every child before clipping, including unloaded children whose changed geometry could shift a later load. It translates coordinates without rescaling, and retains the existing interval checks. A discrepancy, including a one-ULP discrepancy, refuses the remap. This is deliberately conservative: coordinate translations, inclined geometry and subdivision can cause an otherwise valid member to be refused. Moving the model nearer the coordinate origin or choosing representable cut positions may make the split representable. No interval limit or numerical acceptance tolerance was relaxed. Native analysis of an unchanged member is unaffected.

Rerun analyses that subdivide loaded members: manual edits, analysis subdivision, variable-member expansion, planar second-order refinement, plastic collapse and Maxwell section evaluation all reach this remapper. Full and partial distributed loads, axial loads and every spatial load component share the guard. Tests check resultant and first moment for accepted rounded cut positions and refusal for inconsistent geometry. A refused manual edit leaves the original load on the original member.

Planar combination assembly also now propagates arithmetic errors instead of treating them as an absent combination. Earlier branch code could return a successful envelope containing only the other combinations. Checked native and WASM consumers share the fallible implementation; compatibility functions returning `Option` retain refusal as `None`. Spatial combinations keep their refusal and report the established overflow diagnostic before recovery. The original overflow and summary-range assertions remain unchanged.

Recheck saved combination sets from earlier versions of this branch when factors overflowed. The combination omission was introduced by unmerged interval-validation work; it does not establish a main or release advisory. The compensated applied-force notice now excludes models without structural stiffness, while continuing to cover every analysis history with members, shells, connectors or springs.

The opposing-endpoint axial integration cancellation defect is present on main and remains outside this fix, as requested in #2223. It is recorded with a main-kernel replay in the worktree handoff for coordinator triage. No advisory is introduced here.
