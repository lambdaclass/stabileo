# Every active combination is required for design (2026-11-14)

PR #2080 round 16 closes partial-data acceptance in parent `523cd9416e`. Station transfer previously built its combination list from the results that arrived. Removing an entire active combination therefore removed it from both the demands and the concurrent tuples, leaving apparently complete data. Concrete auto verification also accepted any nonempty tuple array and used endpoint forces when an element was missing from a supplied station-demand map.

`computeStationDemands` now takes the expected combination IDs from its active `combinations` argument and refuses missing analysis results before either WASM transfer. Both compact and grouped transfer retain that expected list when attaching loading. Station extraction records the complete combination ID set independently of the governing categories, including combinations with identical or zero demands that win no category. Auto verification checks coverage against that retained set and every governing demand, using the same shared completeness check as station transfer. Every public concrete model entry reaches auto verification; foreign-code member contexts reach station transfer. A supplied station map requires its element entry and complete concurrent tuples; only calls with no station data or combination envelope may use endpoints.

The reproducer removes the first, second or every active result; removes an element entry; removes all tuples; or keeps only one combination's tuples. The final matrix has 153 tests: the unchanged parent fails 96, and 57 controls pass. Empty and undefined tuples were already refused, and complete-data controls already passed. After the fix, all 153 pass. Coverage includes actual linear and P-Delta WASM solves, 2D results lifted to the 3D station input contract, spatial results, compact and grouped station transfer, auto verification, unified verification, the design wrapper and foreign-code member-context construction. The orchestration is TypeScript; no corresponding native implementation or Rust numerical kernel changes here.

The checked-in primary text is `docs/codes/CIRSOC/markdown/cirsoc-201-2025/capitulo-2-simbologia-general-y-definiciones.md` and `capitulo-9-vigas.md`. The formula gives 3.68 cm² at the actual bars, rather than 3.693333333333333 cm² at the assumed bars. The test now explicitly checks the actual depth from geometry and bar diameter, then applies its original formula and unchanged six-place tolerance to providedDepth. Production minimum-steel calculations already use the correct geometry and are unchanged.
