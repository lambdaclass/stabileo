# Member recovery preserves shear rigidity and spatial stiffness (2026-11-15)

PR #2170 round 4 corrects regressions introduced while consolidating recovery for #2143. These are branch regressions, reproduced on `8659d1487`; no new safety advisory is assigned or created.

The planar adapters omitted `gas` when requesting Rust recovery. On a 5 m cantilever with EI = GAs = 20,000 and a unit tip force, integrating section curvature gives rotation `P*x*(2*L-x)/(2*EI)` and deflection `P*x*x*(3*L-x)/(6*EI) + P*x/GAs`. At midspan the correct rotation is 0.00046875 rad; the branch recovers 0.00054375 rad by interpreting the shear-flexible nodal solution as Euler–Bernoulli. Both planar adapters now forward `gas`. Ordinary application 2D model conversion currently supplies no shear area; this fixes the adapters for shear-flexible solver inputs without changing that model-conversion policy.

Spatial TypeScript recovery previously accepted finite positive EI. Delegation accidentally inherited the planar `EI > 1e-6` requirement. An explicit `RecoverySpace` selects the established acceptance criterion in the one Rust validator: planar keeps its cutoff; spatial requires finite EI > 0. Loaded missing, zero, negative and nonfinite stiffness still refuses. Controls use scaled uniform loading, both spatial bending planes, EI below/at/above the planar cutoff and a smaller positive EI, with linear and P-Delta solutions in native and WASM runtimes.

The displacement certificate encloses the error in the member curve propagated from nodal solution error: `sqrt(max(1,S))*||T||^2*||u* - u_computed||`, with S derived from the curve's end-value cubics. It does not enclose subtraction of the undeformed world coordinate from a drawn world coordinate. That subtraction, at y = 4 m in the CI witness, produces a difference of 1.1275702593849246e-17 m against an allowed 3.84086068167685e-18 m. See the inherited floating-point evaluation limitation in [CERTIFY.md](../verification/CERTIFY.md#diagrams-extremes-deflections-and-reactions).

The hover now reads exactly the curve evaluation used for drawing. `compute_member_displacements_2d` owns local transformations, recovery, axial interpolation and the transformation back to global displacement. Drawing only adds world coordinates and scale to that result. The existing JSON shape boundary can return the displacement directly at requested positions, before adding the world coordinate. The certificate regression now compares against that displacement and additionally requires exact equality of all returned components. No bound, tolerance or baseline is enlarged. The certificate remains a translation certificate; recovered interior rotations are not certified by it.

Independent closed forms cover planar tip-force rotation and displacement, distributed loading, both spatial planes, and Euler–Bernoulli controls. Native tests also reconstruct drawn coordinates exactly from raw displacement with several offsets. The existing 24-case/504-station no-couple shape record remains exactly equal. Re-run affected analyses and review recovered displacement, rotation and serviceability. Nodal solutions and member forces are unchanged.

The shared web request builder requires an explicit `gas` property (possibly undefined) and normalizes scalar loads into explicit distributed-load records. This also avoids inheriting the shape API's legacy scalar-load filter during hover consolidation. Boundary cases at, below and above |q| = 1e-10, plus zero load, retain the closed-form displacement without changing any tolerance. Exact source replays of both the branch parent and `origin/main` (`8e5c026b7125f920c7a29141aa375c98c178f9b3`) show the direct TypeScript shape helper silently returns zero at and below this legacy boundary. The coordinator is given this evidence in `.handoff.md`; no new advisory is created. The shared native fallback likewise retains every nonzero scalar load, so native and WASM shape requests cannot silently drop these loads either. The numerical recovery and its refusal checks remain shared.
