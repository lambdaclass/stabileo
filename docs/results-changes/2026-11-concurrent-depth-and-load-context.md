# Selected reinforcement and load context govern design (2026-11-14)

PR #2080 round 8 corrects three numerical design defects reviewed at `d161de3a6c`.

The fixed concrete cage inherited the independently sized cage's assumed effective depth. Independent sizing already evaluated the selected bars at their actual depth, but returned the initial sizing depth as `d`. `d` now denotes the selected bars' depth; `designDepth` preserves the sizing assumption and the footing sizing check reads that explicit field. Fixed reinforcement accepts bar data rather than a calculation result's depth, and derives depth from the current section geometry through the same `effectiveDepth` function. The regenerated [shared-cage witness](fixtures/2080-flange-span-witness.json) uses 2 Ø25 bars, 400 mm depth, 25 mm cover and 8 mm stirrups: d = 354.5 mm. Its shared and independent capacities now agree at 124.06052867929414 kN·m. Round 7's shared capacity, 125.73057047929413 kN·m, was wrong. Capacity-boundary tests check both sides and equality without changing a tolerance.

Steel previously centred a shorter unbraced length on the element and reused that gradient at every demand station. A length alone establishes no brace position. Explicit per-flange brace positions now select the interval containing the station. Both adjacent intervals are evaluated at a brace station and the smaller Cb governs; the declared longest gap remains the conservative Lb for capacity. Whole-member or whole-chain spans retain their diagram credit. Shorter spans without positions, incomplete diagrams and chain declarations without a known containing interval receive no computed credit (Cb = 1). Cache identity includes combination, selected length and interval bounds. Full checks, screening, interaction and certification share this preparation.

Concrete end moments were passed unconditionally to the slenderness check. [CIRSOC 201-2025 §6.6.4.5.3(b)](../codes/CIRSOC/markdown/cirsoc-201-2025/capitulo-6-analisis-estructural.md#c6.6.4.5.3), printed page 140, requires Cm = 1.0 for transverse loads between supports. Its commentary explains that the maximum internal moment must be used. Per-axis load status is now carried by immutable concurrent demands from each combination's raw distributed and point loads. Both compact and grouped station transfers attach the same status. Only explicitly known unloaded spans receive end-gradient credit; missing load information defaults conservatively. Loading on the other bending axis does not discard a known unloaded axis's gradient. Both CIRSOC editions use this conservative rule. Point loads at an endpoint do not count as loads between supports; tests cover both endpoints and immediately interior positions.

The manual test adapter also preserves Nu as its own distinct case alongside NuShear and axialLoads. The CI behaviour test's fabricated records lacked the required forces packet and used `as never`; it now uses typed extracted records, retaining its original category assertions. Corrected fixture behaviour also passes the reviewed parent implementation, so this CI finding requires no production relaxation.
