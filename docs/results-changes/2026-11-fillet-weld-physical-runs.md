# Fillet weld effective length follows the physical run (2026-11-16)

Fixes #2243 and #2244 in the native and WASM weld-group elastic check. Main `d877e0b532004e9383663731f64bb908fbc84221` applies effective-length reduction separately to each drawn segment and omits the short-fillet leg limit. Both issue witnesses silently return passing numeric ratios without an unevaluated diagnostic. The audit's experimental product notice is not a diagnostic on these numeric kernel results. Both issues require coordinator-assigned advisories; this change assigns no SA number and adds no advisory file.

The source is the repository's [CIRSOC 301-2018 chapter J, §J.2.2](../codes/CIRSOC/markdown/cirsoc-301-2018/capitulo-j-proyecto-de-uniones-juntas-y-me.md). Lines 453–459 define effective area and total uniform fillet length, including returns. Lines 521–524 limit the leg to one quarter of the effective length when the fillet is shorter than four nominal legs. Lines 529–545 give the end-loaded reduction: beta is one up to L/w = 100, is 1.2 − 0.002 L/w through 300, and gives effective length 180w beyond 300. The witness inputs explicitly select phi = 0.75 and FEXX = 400 MPa; these are model inputs, not a claim about CIRSOC's default resistance factor. The existing equal-leg throat approximation 0.707 and strength calculation are preserved.

A private `PhysicalWeldRun` is now constructed from connected segment endpoints with equal nominal size and end-loading classification. Endpoint matching is exact, with signed zero canonicalized; no coordinate tolerance is added. Reordering segments or reversing their direction preserves connectivity. Turns and returns of uniform dimensions remain in their connected run. A size or loading change starts a separate uniform run. Disconnected collinear fillets and distinct parallel fillets have separate endpoint components. A branching endpoint with more than two matching incident segments is unevaluated because this input cannot identify the continuing physical fillet. Non-finite geometry and negative sizes are also explicitly unevaluated; zero-length and zero-size drawing pieces supply no resistance or stress-check points. Zero-size pieces retain their geometric length in the reported total, but do not enter the connectivity graph.

Only normalized runs supply effective throat to the group integration. The short-fillet leg limit and long-fillet beta are calculated once using total run length, then distributed uniformly over the run's geometric pieces. Effective area, centroid weighting and polar line inertia all use that same throat. The polar integral includes each piece's self-inertia and parallel-axis contribution, so drawing subdivision cannot change the elastic solution. Raw segments no longer have a separate path into the group stress calculation.

For #2243, the physical fillet is 3 m long with nominal leg 0.006 m and applied in-plane force 1 MN. Effective length is 180 × 0.006 = 1.08 m. Available force is 824644.8 N and utilization is 1.212643310186398. Main returns that failing ratio when the fillet is drawn whole, but returns 0.43655159166710317 when it is drawn as five contiguous 0.6 m pieces. The corrected five-piece result is 1.212643310186398, with effective area 0.00458136 m² instead of 0.012726 m².

For #2244, the fillet length is 0.012 m, nominal leg 0.006 m and force 5000 N. The permitted effective leg is 0.003 m. Main credits 9162.72 N and returns 0.5456894895838791; the corrected capacity is 4581.36 N and utilization is 1.0913789791677582. This applies whether the short fillet is declared end-loaded, loaded along its length, or left at the conservative default. Splitting that short fillet must use the total run length for its leg limit as well.

The [numerical result record](2243-2244-weld-run-diff.json) preserves the audit witness results, corrected outputs, an eccentric case, the branch refusal and unchanged controls.

The shared [78-case fixture](../../engine/tests/integration/fixtures/weld-runs.json) records explicit reference physical runs, independently calculated centroid and polar inertia, expected effective area and maximum elastic stress, and clause-line citations. Native integration tests and the actual web WASM wrapper check the same inputs and expected outputs. Coverage includes both witnesses; uniform and unequal cuts; reversed order and direction; diagonal collinear vertices; short pieces within long runs; disconnected and nearby parallel fillets; size and loading changes; uniform returns; eccentric mixed groups; zero-length pieces; L/w = 3.9, 4, 4.1, 99, 100, 101, 299, 300 and 301; and an ambiguous branch with an unevaluated result. Correct unreduced and along-length-loaded answers are retained controls.

The historical 44-case matrix was introduced by commit A `8f12c86a6`, which adds 26 native tests ignored as known wrong results, with 18 active controls. On its parent/main, enabling those 26 tests fails every one; leaving the ignores gives 18 passes and 26 ignores. Replaying the same matrix through main's WASM build with ordinary assertions gives 26 failures and 18 passes. Commit B removes the ignores and expected-failure markers; all 44 native and 44 WASM cases pass. The WASM fixture import in A had one excess parent-directory component; B corrects that harness path before the main-source replay. The Rust reproducers in A already compiled and failed as intended.

The weld-group API accepts planar weld geometry and in-plane group forces, independently of any structural solver. There is one native dispatcher and one WASM export calling it; there are no separate 2D/3D or linear/nonlinear weld-group implementations to exercise. This change does not merge the separate single-fillet connection calculator, infer connectivity across geometric gaps, or add a user-facing physical-run identifier. Explicit identifiers would require an input/schema migration; ambiguous endpoint branches therefore refuse rather than guess. General overlapping-segment geometry remains outside this run-connectivity correction.

Re-run weld-group checks and review newly failing or unevaluated connections. Whole physical-run length, effective area and eccentric stress can change even when the drawn total length is unchanged.

## Zero-size pieces do not resist load (#2258)

The final review found that zero-size segments still entered physical-run connectivity and endpoint stress sampling on branch head `3ba8b1909`. Three zero-size pieces sharing an endpoint refused an otherwise valid mixed group as an ambiguous run. One or two remote zero-size pieces could also inflate eccentric stress despite having no resisting area. Normalization now returns a private `PhysicalWeldGroup` containing positive-size, positive-length runs plus the separately validated geometric total length. Only those runs supply area, centroid, inertia, beta and stress-check points. Every input piece is validated before filtering; negative or non-finite sizes and invalid coordinates remain refused. A non-finite total geometric length is explicitly unevaluated, including disconnected zero-size pieces.

The additional 15 shared native/WASM cases include the exact mixed-branch shape, all three end-loading declarations, reversed directions and order, signed zero, loaded and unloaded groups, one and two nonresisting eccentric pieces, and groups with no positive throat. Positive-size branches, including the smallest positive finite size, still refuse; a two-piece positive-size run retains its analytical answer. Connected and disconnected overflowing zero-size lengths refuse, while the existing maximum-finite total-length controls retain their answers. Eleven new reproducers fail on `3ba8b1909`; four boundary controls pass. The full fixture now has 78 cases, up from 63 before this review; the 44-case counts above describe the original historical matrix.

For the eccentric reference, the existing `correct_unreduced_answer` fixture supplies the material, resistance factor, geometry, throat area and direct load. The applied moment equals that load times the positive run length. The independent reference uses the straight-run centroid, line polar inertia and endpoint stress, excluding nonresisting pieces, while adding their lengths to the reported total. Expected results are fixed in the fixture with the existing tolerance unchanged.

The branch refusal is introduced only on the unmerged physical-run branch. However, replaying the exact `origin/main` connection-check module at `db3ebf09287830306bf9da0d1d5150f6145a4ec7` also shows silent eccentric-stress inflation from zero-size endpoints. Its public native kernel returns a numeric ratio without an unevaluated reason. For `issue_2258_zero_size_single_piece_eccentric`, main returns maximum stress 1242343551.9107356 Pa and utilization 6.901908621726309; the independent positive-run reference is 35848435.4685185 Pa and 0.19915797482510283. Both report geometric length 1.2 m; the zero-size piece changes only that reported length in the corrected resistance calculation. The WASM export separately withholds non-finite total-length output; that overflow is not a silent WASM result. Coordinator review owns any advisory decision and numbering; this revision adds no advisory.

Mixed groups that were refused because of zero-size branches now receive their positive-run result. Eccentric utilization can decrease when zero-size drawing pieces cease to contribute remote stress-check points. Re-run saved weld-group checks containing zero-size pieces.
