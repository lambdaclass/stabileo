# Candidate diameters and effective end cages (2026-11-16)

PR #2198 round 7 removes three false-refusal paths on the pending directional-cage branch. The existing `directional-stirrup-legs` registry entry covers this work; its applicability and quantities are unchanged. No advisory or results version is assigned here.

When the secondary spacing seed was absent, `secondaryLegCounts` returned only the default two-leg cage. In particular, edition 2005 columns could never offer three or four secondary legs even when strength required them. One shared count expansion now walks from the effective minimum through the existing maximum, whether the seed is present or absent. The bounded selector continues reserving strong representatives for higher counts. The default count remains implicit when no spacing seed exists, preserving existing reinforcement serialization. Planar beams with no secondary demand retain their existing two-leg option list. The strength regressions now exercise both editions and both flexural axes, with demands requiring two, three, four and an unsupported fifth leg. The independent edition-specific capacity arithmetic and actual verifier checks remain. The unsupported 2005 beam spacing table still refuses; this work supplies no substitute regulation.

Both rectangular candidate enumerators now obtain their trial shear depths from `candidateShearDepth`, passing the candidate diameter. Spacing seeds and secondary strength ranking consume that same geometry. The existing longitudinal seed assumption remains unchanged; final verification still decides capacity using its own bar geometry and all concurrent demands.

The review's section is 0.400 m by 1.125 m, with 25 mm cover, 16 mm longitudinal bars, nominal 12 mm stirrups and a trial 6 mm cage. Its secondary trial depth is 0.361 m instead of the previous 0.355 m. Under the existing spacing authority, the 1.069 m outer-leg span needs four legs at that depth; the previous seed incorrectly required five, beyond the supported maximum. Tests cover this exact boundary in beams and columns, both axes and both shear directions. Section widths below, at and above the four-leg boundary retain the unchanged limit: 1.138 m and 1.139 m offer four-leg candidates, while 1.140 m refuses. A 1.121 m control already succeeded before the fix. These dimensions and depths come from the supplied review witness and executable regression arithmetic, not a new regulatory rule.

Seismic end sizing now resolves exactly two effective cages, each explicit end or its fallback. An unused shared 16 mm cage no longer empties the available 8/10/12 mm trial list when both ends declare valid cages. Unused fallback leg counts and spacing no longer tighten the selected ends. Tests mirror the ends, retain a fallback with a different count and tighter spacing, and require refusal with unchanged reinforcement when either end actually depends on the incompatible fallback. The selected spacing and diameter are pinned against the existing hoop authority. Directional leg counts are preserved. Seismic report verification status is unchanged.

The signed reproducer commit precedes the fixes. Running the focused tests against the four e2a9fe179 production files gives 32 assertion failures and 149 passing controls; all four files were byte-identical to the merged parent before fixing. The corrected focused run passes all 181 tests. TypeScript uses the repository's conditional Vitest skip convention for the reproducer commit; the fix removes those skips. There is no separate native cage enumerator or seismic writer. Existing WASM linear/P-Delta and planar/spatial entry regressions are retained.

The two review blockers remain unchanged: secondary torsion minimum (#2225) and spacing demand ignoring axial force (#2214). Column and beam provided spacing still pass through the same `requiredVsForTable` helper. No tolerance, baseline, strength assertion or search budget is relaxed.
