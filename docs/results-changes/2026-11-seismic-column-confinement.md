# Recorded axial demand for seismic column confinement

A primary concrete frame column could report adequate confinement using a zero axial force when no eligible station supplied an axial range, or omit the axial force when passing the column to the tie check. The frame now withholds the confinement check when the recorded range is missing or invalid, or the demand falls in the range where the detailed method needs the count and arrangement of held perimeter bars. Automatic detailing skips that column. Review existing frame reports and verify the tie layout before issuing reinforcement details.

The results notice covers 3D concrete frame projects with saved reinforcement because the saved project metadata does not record the governing axial force. Solved station forces are reused without changing the solver.
