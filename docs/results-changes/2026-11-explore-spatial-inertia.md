# Spatial bending inertia comparisons in Explore

Explore now changes both bending inertias, Iy and Iz, while keeping the resolved torsion constant J. The same rule applies to a change made to all members, one member, or a member split to position a load or support.

Repeat any spatial Explore comparison that changed bending inertia. Some builds changed only one bending inertia. The reviewed branch also scaled J, changing the calculated twist of a cantilever under the same torque. Opening a saved model and solving its original sections uses the properties stored in the model.
