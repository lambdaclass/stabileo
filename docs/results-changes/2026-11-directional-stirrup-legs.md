# Direction-specific stirrup legs (2026-11-16)

Fix #2171 corrects CIRSOC 201-2005 and 2025 secondary shear and combined shear–torsion reinforcement checks for solid rectangular members. A closed rectangular hoop has two effective legs on each face. Extra primary-direction legs do not constitute horizontal crossties. The previous member verifier passed one leg count into both shear checks and reconciled the cage by taking the maximum count in either direction. The provided-column verifier and the shared torsion checker repeated the same assumption.

The reinforcement model now stores `secondaryLegs` separately from primary `legs`. Absence means two, including on saved projects. Beam region stirrups, column ties, batch editing and beam-line editing expose and preserve that value. Restore migration writes the conservative default without changing the primary count. Editing another field preserves declared horizontal crossties. Beam-line projection bounds both directional provisions at the supports, and equalization preserves both maxima. Reinforcement identity normalizes absent and explicit two-leg defaults, so migration does not invalidate an otherwise unchanged design receipt.

`DirectionalLegs<'primary'>` and `DirectionalLegs<'secondary'>` are distinct immutable types, constructed from the corresponding cage field. The common shear provision function requires the matching direction; a primary token cannot satisfy a secondary call. Member shear results preserve that direction in their type, so a primary result cannot occupy the secondary result field. Cage reconciliation shares spacing while retaining separate counts. Provided-column checks use the same directional provision path. The native section evaluator receives the resulting steel area for that orientation, rather than interpreting a cage's primary count. The shared torsion checker compares each face's required shear-plus-torsion steel, using the existing torsion minimum, with that face's provision. Torsion's `At` remains limited by one outer hoop leg; adding crossties cannot multiply it.

The source for transverse shear area is CIRSOC 201-2025 §22.5.8.5.3; the combined transverse steel and minimum are §22.7.6.1 and §9.6.4.2. The existing two-orientation concrete-section limit from #2142/#2169 is unchanged. The correction does not add a native torsion implementation: native member checks take a scalar `Av` for one orientation, and the web checker discloses that native torsion is not rechecked. Both web editions use the native section evaluator through WASM. Real spatial linear and P-Delta solves exercise grouped and compact station transfer and auto, unified and manual design wrappers. Planar linear and P-Delta solves have no secondary shear or torsion degrees of freedom and remain answered controls.
