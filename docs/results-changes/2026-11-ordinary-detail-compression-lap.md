# Compression lap lengths in the ordinary construction catalogue

The ordinary T-03 catalogue again uses the released compression lap schedule. An intermediate integration build applied the reinforcement sheets’ additional length to the ordinary catalogue. For the checked H-20, ADN 420, 16 mm row this printed 640 mm. The released schedule prints 480 mm. The H-21 and H-25 controls print the same row in both profiles. The enabled reinforcement sheets retain their existing conservative convention.

Review T-03 if issued from an intermediate build with the reinforcement sheets disabled. The comparison uses the saved concrete and reinforcement properties and the existing rounding rule. [CIRSOC 201-2025, Chapter 25, §25.5.5.1](../codes/CIRSOC/markdown/cirsoc-201-2025/capitulo-25-detalles-de-armado.md) gives the compression lap rule for concrete of at least 20 MPa.
