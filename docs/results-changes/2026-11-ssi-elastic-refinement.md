# SSI corrects elastic residual plateaus

Issue #2011 is an explicit false refusal introduced by the stricter physical equilibrium check in #1940. With no soil springs, SSI reconstructed and solved the same secant system after every rejected residual check. The displacement was reset to the same rounded answer, so additional iterations could not improve equilibrium. The exact retained cantilever converges in its original frame on origin/main but its rotated copy exhausts the iteration limit. Main returns `converged: false`; this observation is not a silent wrong engineering result.

Both SSI dimensions now keep a secant state containing its matrix, factorization and current independent displacement. An unchanged matrix reuses that state. A rejected physical residual supplies a correction right-hand side through the same constraints and support frames used for assembly and force recovery. Linear analysis and SSI share the finite-checked elastic correction loop; linear retains its existing displacement-accuracy test and SSI retains its existing physical equilibrium criterion. Soil secants are evaluated again after correction, and both stiffness change and physical equilibrium must pass before acceptance.

A binary64 displacement can still sit on a rounding plateau after residual correction. The common equilibrium utilities retain the best measured field and search nearby coherent roundings, with diagonal residual corrections, before SSI checks the same physical residual again. This bounded search changes displacement representation; it never changes the applied load or the acceptance tolerance.

No tolerance, comparison allowance or stability threshold is increased. Models with soil in its linear range follow the same correction path. A changing nonlinear secant still causes a new solve. Regression controls preserve the complete original nonlinear-soil responses bit for bit, including unfinished iterations, and retain refusals for unattainable residuals and prescribed support motion. Existing SSI follow-ups #1993, #1995 and #1987 are outside this change.

Re-run affected SSI analyses and dependent results. Convergence status, iterations, displacements, reactions, constraint forces and member forces may change. The registry requires explicit SSI history or stored 3D support curves, together with structural stiffness. Unknown analysis history alone does not select ordinary linear frames or shell projects. The changed results are SSI analyses without soil or with soil remaining in its linear range. Saved projects do not retain the advanced SSI panel spring list or soil response displacements, so an explicit SSI history or stored support curves conservatively retain the notice when a spring may have remained in its linear range; the notice does not claim that changing nonlinear-soil responses moved. Other notices keep their existing treatment of unknown histories (#2072).

Targeted coverage retains the exact #2011 seeded reproducer and adds 2D/3D rotations, consistent unit scaling, both sides of sparse dispatch, active soil in its linear range, nonlinear-soil baselines, iteration exhaustion, strict residual refusal and a 3D typed-units boundary guard. Native typed and JSON entry points and the actual public WASM exports are checked separately. The test-only parent commit retains ignored reproducers for the before/after evidence.

The linear-soil control uses the reciprocal of the frame’s independently computed tip compliance for its spring stiffness. Its independent linear model includes the same spring as a support. Both dimensions require the model without that spring to fail the same displacement comparison, and native JSON and WASM exports retain these load-bearing spring cases (#2072).
