# Sub-limit member load intervals are refused (2026-11-16)

The original #2222 kernel returned zero for a partial transverse load narrower than its absolute cutoff of `1e-12`. Both spatial bending planes shared that kernel. The static self-check counted the assembled right-hand side, so a missing load could return zero responses with passing balance checks. The checked-in witness is `engine/tests/fixtures/narrow-span-2222.json`: nodes at `x=0,3,6`, fixed outer ends, with a downward unit resultant on `[1.5,1.5000000000005]` of member 1. This input now returns a localized refusal.

The final approach in review round 7 replaces the branch's concentrated-load conversion with a domain restriction. Every member load interval must have finite endpoints, satisfy `0 <= a <= b <= L`, and satisfy `(b-a)/L >= 1e-10`. The relative limit uses the native member geometry limit, named `MEMBER_GEOMETRY_LIMIT` in the native and web validators. Equality is supported. Zero-width, subnormal, adjacent representable and all smaller positive intervals are refused, regardless of load magnitude, component or resultant. A zero resultant does not exempt an opposing pair of intensities.

Native planar and spatial load validation shares one interval check before assembly, including typed inputs, prepared models, load sessions and nonlinear solves. Recovery and saved force-diagram APIs apply the same check. Errors identify the element and interval; standalone recovery APIs, which have no element identity in their input, identify `Member recovery`. Infallible native numerical kernels reject violations by panic; fallible solve and WASM boundaries return an error before invoking those kernels.

Web input adapters validate before decomposing or filtering components. Planar Maxwell and plastic remapping, the model splitter, analysis subdivision and variable-member expansion share the web interval validator. Both the original source and each positive child overlap are validated. Empty intersections are omitted because they carry no source load; positive sub-limit fragments refuse the operation. Mapped endpoints are validated again against the actual child length, including collapsed endpoints. No unsupported load is dropped, snapped to an end, or replaced by forces or couples. The force-pair, residual-couple, interior-station and collapsed-peak machinery added on this branch has been removed.

The previous round's exact remapping witness uses source piece `[0,2]`, child length `2 - 2^-51`, interval `[1.5 - 2^-52,1.5]`, and uniform intensity `2^52`. It is now refused before remapping. Regressions cover the original issue, source and child overlap boundaries, both spatial bending planes, transverse and axial components, uniform, triangular and opposing intensities, native and WASM entry points, and supported ordinary loads with reaction checks. Adjacent representable widths on both sides of the limit retain the exact refusal boundary.

Rerun affected models. A previously saved answer for an unsupported interval is unusable; the new solve returns a refusal requiring an explicitly revised load model. The existing `narrow-partial-loads` registry entry retains numerical coverage for partial-load models: supported intervals between the new geometry limit and the splitter's former cutoff are now retained with their varying intensities, and supported near-full endpoints are no longer snapped. Automatic analysis subdivision and variable-member expansion can therefore change responses and dependent checks. The existing planar plastic remapping entry retains its narrower factor, history, mechanism and solve-status coverage. Their quantity scopes have not been broadened. Explicit model edits or loads lost by a past edit must be recreated before solving; an already deleted load cannot be recovered from the saved model. This record assigns no advisory; the worktree handoff records main exposure for coordinator classification.

## Saved-result refusal and rounded child intervals (round 8, #2223)

Saved planar and spatial results now pass the shared interval validator before envelope sampling, combination recovery, section-stress evaluation, beam-station extraction or certified-demand extraction. Non-finite force records are refused before evaluation. Native combination and envelope paths validate too; a finite but invalid interval can no longer reach an infallible kernel through those fallible APIs. The direct member-deflection constructors enforce both endpoint bounds as well as the relative width limit. Internal span-rotation recovery uses the member length recorded with its loads, avoiding disagreement with independently rounded summary geometry.

When a member is subdivided, supported partial endpoints are mapped from the source overlap to the actual geometric length of the child. The common remapping operation validates both the source overlap and the mapped child interval. Manual editing, analysis subdivision, variable-member expansion and planar second-order refinement supply those lengths. For example, a member from `1000.1` to `1004.1` cut at `2/3` previously assigned the first child an endpoint `2.66666666666665` beyond its rounded geometric length. The load now remains within the child and the analysis can proceed. Supported partial loads can therefore produce different dependent subdivision results; the existing partial-load registry entries retain their numerical scope and now explain this in every supported language. No general result baseline or tolerance changes.

The axial fixed-end-force proof checks the shared integration formula over its original physical input ranges, including unsupported endpoint orderings. The public kernel checks the shared supported-interval predicate before calling that formula. Invalid intervals are exercised by the refusal regressions rather than being passed to an infallible kernel. Kernel assertions do not construct floating-point error messages; fallible validators retain the member-specific error text.
