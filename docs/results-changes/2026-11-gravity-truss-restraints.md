# Independent panel decks joined by a restrained truss

Panel gravity previously treated a support pin at an end of a connecting truss as evidence of load transfer between the two decks. For a concentric truss the deck connectivity check now uses bilateral translational restraints at both ends. Offset trusses still require full restraints for the exception. A released axial translation continues to block the independent-deck classification.

The regression uses a 60 m² bay and a separately supported shell rising 3 m across its 6 m width. The fixed plan gives the bay 60 kN and the shell its true surface area times the specified 1 kN/m² dead pressure. The same loads are generated with pinned ends or fixed ends on the truss.

A rafter opening is reported only when the attached shell trace bounds it. If disconnected shell infill was needed to establish that evidence, the offset-attachment refusal identifies the rafter. The message identifies distances for bounded gaps as plan stations along the rafter run. Regenerate automatic gravity and rerun the analysis for affected projects.
