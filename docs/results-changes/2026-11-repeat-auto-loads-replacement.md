# Keep Auto Loads replacement idempotent

When a new Auto Loads plan keeps a wind action but stops generating one of its cases, replacement can remove the last loads from the old case. The old case previously entered the combination set once the evidence that Auto Loads had emptied it was gone. In the review build, this happened on the second Apply. In the baseline, it could happen on the first. The obsolete combination could change which results are evaluated in an envelope.

Preview and Apply now use the same record of cases emptied by replacement. A genuinely empty manual case and a case with surviving effects stay eligible. Replacing an identical plan again preserves the combination IDs and their result scope memberships.

For projects generated by an affected build, review which empty cases are intended alternatives. Earlier saves could already have lost the information that distinguishes an obsolete case. Remove obsolete cases after reviewing their references, then regenerate the load combinations and rerun the analyses and envelopes.
