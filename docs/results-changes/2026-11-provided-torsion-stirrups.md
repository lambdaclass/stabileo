# Torsion checks every returned stirrup cage (2026-11-14)

PR #2080 round 15 corrects two findings in parent `bc350f029f`.

The prepared concrete verifier checked transverse torsion reinforcement only if the caller fixed longitudinal torsion steel. Fixing stirrups alone, or using the shear designer's stirrups, skipped transverse capacity and torsion spacing. Every returned cage now passes through `checkProvidedTorsion`, regardless of the presence of `fixed.torsion`. An omitted longitudinal override retains the design-level Al requirement; an explicit override is still checked. Insufficient transverse provision or excessive spacing fails torsion, overall verification and its diagnostics. Direct and prepared calls share this unconditional path, including preliminary and final concurrent calls. Negligible torsion retains its existing neglect rule. This does not certify torsion detailing or change the existing engine torsion-not-rechecked disclosure.

The witness uses a rectangular beam with b=0.3 m, h=0.6 m, cover=0.025 m, fc=25 MPa, fy=420 MPa, and two-leg 8 mm stirrups at 0.275 m. With V=0, T=30 kN·m and M=20 kN·m, the parent returns torsion `ok` unless longitudinal torsion steel is also fixed. The required At/s is 4.271172651305651 cm²/m; each outer leg provides 1.8278357257249704 cm²/m. The corrected result fails. The existing wrapper's spacing limit for this geometry is 0.19599999999999998 m; it is unchanged. Separate tests isolate both sides of the spacing and transverse-capacity limits and retain a correctly accepted cage.

The [main replay](2080-round15-main-witness.json) uses the exact designer from `origin/main` at `013485aa2629a05672403919060cc1397f510fd1`, loaded temporarily within this worktree and using the initialized current WASM section kernels. Main has no fixed-cage API. Its returned designed cage has the same 0.275 m spacing and insufficient outer-leg steel, yet both torsion and overall status are `ok`. The existing standalone 2025 torsion checker gives ratio 2.3367377008738495 for those actual stirrups. Thus the main replay demonstrates silent acceptance of inadequate returned stirrups, beyond the branch-specific optional-argument bypass. Historical release binaries were not tested. The exposure is tracked as #2141, with the expected-failure witness registered and retired in round 16. The coordinator decides any advisory and its number; this change creates none.

The INTI 2.I.1 regression was introduced by `823da327c1c0a15065fc5cb49f335de3df388fa6`, which changed `checkFlexure().d` from the sizing depth to the selected bars' depth while leaving required-steel quantities at the sizing depth. For the published inputs, the sizing depth is 0.366 m and the chosen 20 mm bars sit at 0.364 m. Main's sizing answer is valid. `d` again equals `designDepth`, alongside the required-steel fields; `providedDepth` explicitly records the actual checked bars. Both automatic sizing and fixed verification construct provided depth, stress block and strain through `providedFlexureState`. Fixed verification derives this depth from the receiving section and supplied bar diameter, ignoring stale result fields. Capacity, minimum-steel and ductility checks still use the actual bars' depth. No engineering formula or test tolerance changed. The original INTI test is unchanged.

Coverage includes 2005/2025, both section axes, beams/columns/walls, direct/prepared/concurrent checks, all four fixed-stirrup/fixed-torsion combinations, neglect and spacing boundaries, transverse-capacity boundaries and zero-torsion controls. Compact and grouped real 3D linear/P-Delta WASM results reach auto verification, unified verification and the design wrapper; real 2D linear/P-Delta results check torsion-free controls and both depth fields. There is no separate native implementation of this TypeScript orchestration, and the 2D solver has no torsion degree of freedom. The Rust section kernels are unchanged.

Re-run saved concrete designs and review torsion failures and the provided stirrups. Consumers of selected-bar geometry should use `providedDepth`; `d` describes the required-steel sizing state. Detailed longitudinal torsion bar placement, consolidation of the two torsion standard implementations and a broader result-type redesign remain outside these two findings.
