A square plate with a notch from its left edge to the centre is pulled apart at the top. The AT2 phase-field model represents the crack as a damage field d between 0 (intact) and 1 (broken), smeared over a length ℓ. The experiment pane runs the Stabileo Rust implementation in Stabileo’s viewer; the orange curve is what the author’s Python code computed.

What the paper shows

The reference repository provides a Python finite-element implementation of AT2 fracture with three examples: a tensile bar, a notched plate and three-point bending. The method and comparisons on this page refer to that code at commit 61037c6.

The model

Displacement u and damage d are both bilinear on quadrilaterals, integrated with 2×2 Gauss points; plane strain, small strain, quasi-static loading.

  • Elasticity at fixed d: div(g(d) C : ε(u)) = 0 with g(d) = (1 − d)², applied to the whole stress.
  • Damage (AT2) at fixed u: (Gc/ℓ + 2H) d − Gc ℓ Δd = 2H.
  • Driving energy: H = ψ+ = ½ Σ σi εi over the positive principal strains, with σi the undamaged principal stresses. This reference-code hybrid split degrades the whole elastic stress. In mixed strain states a positive principal strain can pair with negative stress, giving negative driving energy and potentially negative damage. History mode clamps the driving energy to its nonnegative previous maximum; it does not impose nodal damage bounds.
  • Alternating solution per load step: solve u with the current d, then d with the new u, until the elasticity residual ‖K(d)u − f‖ falls below 10−5.
  • Irreversibility: none in the reference code; damage is recomputed from the current energy and is not bounded by 1. to keep it on unloading (not in the reference).

Units are kN and mm. The 1D uniaxial-stress AT2 estimate σc = √(27 E Gc / 256 ℓ) ≈ 2.82 kN/mm² here, so ℓ behaves as a strength as much as a regularisation length: and the peak load falls. The mesh matters too: the crack band needs elements a few times smaller than ℓ; .

How we reproduced it

  1. The author’s code (commit 61037c6, MIT licence) was run unmodified for its three examples in Python 3.12.15 with numpy 2.1.3 and scipy 1.14.1; every step’s force, iteration count, residual and damage range, and nodal fields at chosen steps, were saved with a manifest of versions and checksums.
  2. The Rust implementation regenerates the same meshes (bit-identical), applies the same boundary conditions, loop and stopping rule, and solves with the Stabileo engine’s sparse Cholesky factorisation.
  3. 30 named checks compare the two, each with a stated tolerance, in continuous integration. The browser bundle and the replay on this page are checked separately against the native build.

Limitations

  • Agreement with a reference code is not validation against experiments, and none of this is an engineering certification.
  • The reference refines a small box around the notch tip. Outside it the element width exceeds three length scales and the height exceeds two; the horizontal crack band is under-resolved.
  • The unconstrained reference discretization can overshoot intact and broken damage limits. Negative damage gives degradation above intact stiffness. Assembly uses interpolated damage at quadrature points; nodal extremes alone do not measure the assembled stiffness error. The solver retains these values; the replay field and colour scale clamp them for display.
  • The alternating scheme is not accelerated; at unstable crack growth it can take hundreds of iterations in one step.
  • Browser runs are limited in mesh size and parameter range.
