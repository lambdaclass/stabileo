## Independent calculation

`make audit.1088` reads the checked-in `engine/tests/metamorphic_corpus/nightly/issue-1088.json`. The implementation and output are retained in `docs/verification/issue-1088-rank.py` and `docs/verification/issue-1088-rank.json`. It does not import or call the engine, an engine matrix, or an engine stability decision. It reads decimal input values as exact rational numbers.

For a member with coordinate differences `(dx, dz)`, put `s = dx² + dz²`. Define axial extension numerator `a = dx Δux + dz Δuz` and end bending measures `b_i = s θ_i + dz Δux - dx Δuz`, `b_j = s θ_j + dz Δux - dx Δuz`. Integrating the axial strain and cubic transverse interpolation curvature gives the member quadratic form, up to the positive multiplier `EI / s^(5/2)`:

`(A/I) s a² + 4 b_i² + 4 b_i b_j + 4 b_j²`.

Minimizing over a released end rotation leaves `3 b_other²`; releasing both ends leaves only the axial term. The actual input has positive E, A and I, no shear area, and a fixed support only at node 1. No artificial rotational stiffness or rounding cutoff is used.

Each member's scaled matrix is positive semidefinite. The kernel of their sum is the intersection of their kernels, which is unchanged by restoring each positive `EI / s^(5/2)` multiplier. Exact rational elimination of the summed scaled matrices therefore determines the rank of the actual stiffness without a numerical rank threshold. A separate 80-digit Decimal assembly restores the multipliers and prints the physical stiffness matrix.

| Model | Free DOFs | Exact stiffness rank | Active DOFs | Active rank |
| --- | ---: | ---: | ---: | ---: |
| Original input | 6 | 4 | 5 | 4 |
| Add restraint ux at node 3 | 5 | 4 | 4 | 4 |

The original model has an unused rotation at node 2, where both member ends are released, and a distinct physical mechanism. With node 2 stationary, a unit rotation of member 2 gives node 3 `(ux, uz, θ) = (-10.24770562597325, 2.372435061406389, 1)`. The rational calculation verifies that this vector is in the kernel of each member separately. The restored Decimal stiffness gives maximum absolute null residual `9.597e-78` at 80 digits. This proves a moving-node mechanism even after removing the unused joint rotation. Plane embeddings restrain the out-of-plane DOFs and preserve this in-plane null direction.

The only applied load is thermal on element 1. A load that does not excite the null direction does not make the stiffness full rank or make the resulting displacement field unique. The independent calculation establishes initial elastic rank; it does not claim a nonlinear stability result at an unspecified deformed equilibrium.
